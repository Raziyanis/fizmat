while циклі

n = 2026
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)

Цикл денесі шарт ақиқат болғанша қайталанады.

n % 10 — соңғы цифр, n // 10 — соңғы цифрсыз сан.

Бағдарлама цифрлардың қосындысын табады: 2 + 0 + 2 + 6 = 10.

while денесінде шартты өзгертетін бір нәрсе болуы керек — әйтпесе цикл шексіз болады.

Сыныппен трассировка жасаңыз: n = 2026, 202, 20, 2, 0. Цикл 4 итерация жасады. Нәтиже іске қосылып тексерілді.
