Цикл while

n = 2026
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)

Тело цикла повторяется, пока условие истинно.

n % 10 — последняя цифра, n // 10 — число без последней цифры.

Программа находит сумму цифр: 2 + 0 + 2 + 6 = 10.

В теле while что-то должно менять условие — иначе цикл станет бесконечным.

Протрассируйте с классом: n = 2026, 202, 20, 2, 0. Цикл сделал 4 итерации. Вывод проверен запуском.
