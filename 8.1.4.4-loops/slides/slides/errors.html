Частые ошибки

1. Конец range

range(1, 10) — это 1…9, число 10 не входит.

range(1, n + 1)

2. Бесконечный цикл

В теле while забыли изменить переменную из условия.

n = n // 10

3. Отступ

print внутри цикла выводит на каждой итерации, после цикла — один раз.

print(s)

Покажите третью ошибку: сдвиньте print(s) в тело цикла в примере с суммой — программа выведет 1, 3, 6, 10, 15 вместо одного числа 15.
