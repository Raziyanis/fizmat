Одномерный массив и список

Когда значений много — оценки за четверть, покупки, температура за неделю, — заводить отдельную переменную для каждого неудобно. Их хранят в одном списке под одним именем.

Основные понятия

Одномерный массив

ряд значений одного вида, у каждого есть свой номер. Например, оценки ученика за четверть.

Список (list)

так в Python записывают одномерный массив: [5, 4, 5, 3] — значения в квадратных скобках через запятую.

Элемент

одно значение в списке: число, слово или другое значение.

Индекс

номер элемента. Счёт начинается с 0: первый элемент — a[0].

Длина

сколько элементов в списке: len(a).

Метод

команда, которую выполняет сам список: a.append(7). О методах — на следующем этапе.

list — список

Простыми словами: список — как ряд пронумерованных ящиков на одной полке. В каждом ящике лежит одно значение, а у всей полки одно имя.

Где применяется

  • Оценки за четверть: marks = [5, 4, 5, 3]
  • Список покупок: shop = ["хлеб", "молоко"]
  • Температура за неделю: t = [12, 15, 9, 18, 21, 24, 20]

Не подходит: если значение одно — хватит обычной переменной: age = 14.

Как записать: a = [3, 8, 1]

Определение

Одномерный массив — упорядоченный набор элементов, у каждого из которых есть номер (индекс). В Python одномерный массив записывают как список (list): элементы перечисляют в квадратных скобках через запятую.

Синтаксис

имя = [элемент1, элемент2, …]

Пустой список: a = []. Элемент списка можно заменить: a[0] = 10.

Примеры

Кнопка «Открыть в редакторе» переносит пример в редактор ниже — там его можно изменить и запустить.

Важно знать

  • Скобки у списка квадратные, элементы разделяют запятой.
  • Текст в списке пишут в кавычках: ["хлеб", "молоко"]. Без кавычек Python примет слово за имя переменной и выдаст NameError.

Свойства списка

  • Упорядочен: у элементов постоянный порядок; новые элементы append ставит в конец.
  • Изменяем: после создания элементы можно заменять, добавлять и удалять.
  • Допускает повторы: одно и то же значение может стоять в списке несколько раз — [5, 4, 5].

Список — одна из четырёх встроенных коллекций Python. Остальные — кортеж (tuple), множество (set) и словарь (dict) — изучают позже.

Связь с математикой

В математике последовательность записывают как a₁, a₂, …, aₙ. В Python нумерация начинается с нуля: a[0], a[1], …, a[n − 1].

Простыми словами: индекс — номер места в списке, как номер места в очереди. Только счёт начинается с нуля. С конца считают отрицательными номерами: −1 — последний.

  • Исправить цену третьего товара: price[2] = 900

Как записать: a[0], a[-1], a[2] = 7, a[1:3]

Определение

Индекс — целое число, номер элемента в списке. Выражение a[i] даёт элемент с индексом i. В списке из n элементов индексы идут от 0 до n − 1, а с конца — от −1 до −n.

Синтаксис

список[индекс]

Примеры

Важно знать

  • Первый элемент — a[0], а не a[1].
  • Последний — a[-1] или a[len(a) - 1].
  • Индекс — только целое число: a[1.5] — ошибка TypeError.

Срез — несколько элементов сразу

Срез a[i:j] — новый список из элементов с индексами от i до j − 1: элемент с индексом j не входит. Без начала срез идёт с первого элемента: a[:3]; без конца — до последнего: a[2:].

Через срез можно заменить сразу несколько элементов: a[1:3] = [20, 21]. Если новых элементов больше или меньше, чем заменяемых, длина списка меняется.

for x in a — перебор списка, len(), sum(), max(), min()

Простыми словами: цикл for проходит по списку, как учитель по журналу: берёт по очереди каждый элемент. Функции len, sum, max, min смотрят на весь список сразу. Это не методы списка: их пишут перед скобками — len(a), а не a.len().

Где применяется

  • Средний балл: sum(marks) / len(marks)
  • Самая высокая температура недели: max(t)
  • Вывести все покупки по одной: for x in shop: print(x)

Не подходит: чтобы изменить список — добавить или удалить элемент, — нужны методы списка.

Как записать: for x in a:, for i in range(len(a)):

Определение

Перебор — обработка всех элементов списка по очереди в цикле. Встроенные функции работают со всем списком: len(a) — количество элементов, sum(a) — сумма, max(a) и min(a) — наибольший и наименьший элемент.

Синтаксис

for x in a:

for x in a даёт сами значения, for i in range(len(a)) — номера, а значение берут как a[i].

Примеры

Важно знать

  • sum, max и min работают с числами. Для пустого списка max([]) выдаёт ошибку ValueError.
  • Деление / даёт дробное число: sum([4, 5]) / 2 = 4.5.
  • Строки внутри цикла сдвигают на 4 пробела.

Перебор циклом while

Индекс заводят вручную: начинают с 0 и после каждого шага увеличивают на 1, пока он меньше len(a).

Генератор списка

Связь с математикой

Среднее арифметическое = сумма элементов : их количество, в Python — sum(a) / len(a).

append(), insert() и extend() — добавить

Простыми словами: append — встать в конец очереди. insert — пропустить кого-то вперёд на нужное место: остальные сдвигаются. extend — в конец очереди встаёт сразу целая группа.

Где применяется

  • Добавить покупку в конец списка: shop.append("сыр")
  • Записать в список оценки, введённые с клавиатуры: marks.append(int(input()))
  • Поставить срочное дело первым: todo.insert(0, "уроки")
  • Добавить сразу несколько покупок: shop.extend(["сыр", "чай"])

Не подходит: чтобы заменить элемент, метод не нужен — a[i] = x.

Как записать: a.append(x), a.insert(i, x), a.extend(b)

Определение

append(x) добавляет элемент x в конец списка. insert(i, x) вставляет элемент x на место с индексом i, а элементы правее сдвигаются на одну позицию. extend(b) добавляет в конец списка все элементы списка b.

Синтаксис

список.append(x) · список.insert(индекс, x) · список.extend(другой_список)

Примеры

Важно знать

  • append добавляет ровно один элемент за раз: append([7, 8]) добавит один элемент — весь список [7, 8]. Чтобы добавить 7 и 8 по отдельности, нужен extend([7, 8]).
  • Соединить два списка можно знаком +: c = a + b — получится новый список, а a и b не изменятся. extend же меняет сам список.
  • Методы ничего не возвращают: a = a.append(5) — ошибка, в a окажется None. Пиши просто a.append(5).
  • insert: сначала номер, потом значение — insert(0, "а").
  • Ввод списка с клавиатуры: пустой список и цикл с append.
Попробуй сам

Запомни: append — в конец, insert(i, x) — на место i, extend(b) — все элементы b в конец.

pop(), remove(), del и clear() — удалить

Простыми словами: pop достаёт ящик по номеру — по умолчанию последний — и отдаёт его тебе. remove ищет вещь по названию и выбрасывает первую такую. del a[i] выбрасывает ящик с номером i, ничего не отдавая. clear освобождает всю полку.

Где применяется

  • Отменить последнее действие: history.pop()
  • Вычеркнуть купленный товар: shop.remove("хлеб")
  • Обслужить первого в очереди: queue.pop(0)
  • Очистить корзину после оплаты: cart.clear()

Не подходит: удалить все одинаковые элементы сразу — remove убирает только первый.

Как записать: a.pop(), a.pop(i), a.remove(x), del a[i], a.clear()

Определение

pop(i) удаляет элемент с индексом i и возвращает его; без аргумента удаляет последний. remove(x) удаляет первый элемент, равный x. del a[i] удаляет элемент с индексом i и ничего не возвращает; del — не метод, а команда языка Python, поэтому её пишут без точки и скобок. clear() удаляет все элементы: список становится пустым.

Синтаксис

список.pop(индекс) · список.remove(x) · del список[индекс] · список.clear()

Примеры

Важно знать

  • pop удаляет по номеру, remove — по значению.
  • pop(i) и del a[i] удаляют один и тот же элемент, но pop возвращает его, а del — нет.
  • del a без индекса удаляет весь список вместе с именем: после этого print(a) выдаст NameError. Чтобы оставить пустой список, используют clear().
  • Если элемента нет, remove выдаёт ошибку ValueError. Сначала проверь: if x in a:.
  • pop из пустого списка выдаёт ошибку IndexError.
Попробуй сам

Запомни: pop(i) — «убери номер i», remove(x) — «убери значение x», del a[i] — «убери номер i, он не нужен», clear() — «убери всё».

sort(), reverse() и copy() — порядок

Простыми словами: sort — построить класс по росту, от низкого к высокому. reverse — развернуть строй: последний встаёт первым, рост не сравнивают. copy — сфотографировать строй, чтобы помнить, как стояли до перестановки.

Где применяется

  • Оценки по возрастанию: marks.sort()
  • Рейтинг от лучшего к худшему: scores.sort(reverse=True)
  • Новые сообщения сверху: msgs.reverse()
  • Отсортировать, но сохранить исходный порядок: b = a.copy(), затем b.sort()

Не подходит: чтобы узнать только самое большое число, сортировать не нужно — есть max(a).

Как записать: a.sort(), a.sort(reverse=True), a.reverse(), b = a.copy()

Определение

sort() упорядочивает элементы списка по возрастанию: числа — от меньшего к большему, слова — по алфавиту. С аргументом reverse=True — по убыванию. reverse() переставляет элементы в обратном порядке. copy() возвращает новый список с теми же элементами: изменения копии не меняют исходный список.

Синтаксис

список.sort() · список.reverse() · список.copy()

Примеры

Важно знать

  • sort меняет сам список и возвращает None: b = a.sort() — в b окажется None.
  • reverse не сортирует, а только переворачивает: [3, 1, 2] → [2, 1, 3]. По убыванию сортирует sort(reverse=True).
  • b = a не копирует список: это второе имя того же списка, и b.sort() изменит и a. Копия — b = a.copy(); так же работают list(a) и срез a[:].
  • Слова Python сравнивает по кодам букв: заглавные идут раньше строчных, а казахские буквы Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І и буква Ё — после Я.
  • Числа и слова в одном списке отсортировать нельзя — ошибка TypeError.
Попробуй сам

Запомни: sort() — по возрастанию, sort(reverse=True) — по убыванию, reverse() — в обратном порядке. Они меняют сам список; чтобы сохранить исходный, сначала сделай copy().

index() и count() — найти

Простыми словами: index отвечает на вопрос «на каком месте стоит?», count — «сколько раз встречается?». Сам список они не меняют.

Где применяется

  • Место ученика в рейтинге: top.index("Тимур") + 1
  • Сколько пятёрок в журнале: marks.count(5)
  • Есть ли товар в списке: "сыр" in shop

Не подходит: index для элемента, которого нет, — будет ValueError. Сначала проверь через in.

Как записать: a.index(x), a.count(x), x in a

Определение

index(x) возвращает индекс первого элемента, равного x. count(x) возвращает, сколько раз x встречается в списке. Оператор x in a даёт True, если x есть в списке, и False, если нет.

Синтаксис

список.index(x) · список.count(x)

Примеры

Важно знать

  • index находит только первый подходящий элемент.
  • count элемента, которого нет, даёт 0, а не ошибку.
  • in — не метод, а оператор: его пишут без точки и скобок.
Попробуй сам

Запомни: index — «где?», count — «сколько раз?».

Какой метод подходит?

Прочитай ситуацию и выбери метод или функцию. Подсказка: «в конец» — append, «на место» — insert, «по номеру» — pop, «по значению» — remove, «где?» — index, «сколько раз?» — count.
