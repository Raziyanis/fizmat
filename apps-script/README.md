# Урок «Математические функции» — онлайн-версия (Google Apps Script)

Ученики открывают обычную ссылку без регистрации, вписывают класс, фамилию и имя — система проверяет их по вашему списку — и проходят урок.
Учитель на своём экране видит в реальном времени:

- **Доску ответов**, как в Padlet: учитель задаёт вопрос, у учеников всплывает окно, ответы появляются карточками с именами.
- **Ленту попыток**: каждый выбор и каждую формулу ученика, верную (зелёным) и ошибочную (красным), с подсказкой, которую он получил.
- **Ответы из урока**: «Мои ожидания», «Где пригодится», комментарии из итогов.
- **Прогресс**: кто на каком этапе, сколько решил на каждом уровне, самооценку.

Все данные лежат в вашей Google Таблице.

## Файлы

| Файл | Что это |
|---|---|
| `Code.gs` | серверная часть |
| `Lesson.html` | страница урока для учеников (собирается из `lessons-8/index.html` командой `python3 tools/build_gas.py`) |
| `Teacher.html` | экран учителя |

## Установка (один раз, ~10 минут)

1. Создайте новую Google Таблицу (sheets.new), назовите, например, «Урок 8 класс — функции».
2. В таблице: **Расширения → Apps Script**.
3. В редакторе:
   - откройте файл `Code.gs`, удалите всё и вставьте содержимое `Code.gs` отсюда;
   - нажмите **«+» → HTML**, назовите файл `Lesson` (без `.html`), вставьте содержимое `Lesson.html`;
   - ещё раз **«+» → HTML**, назовите `Teacher`, вставьте содержимое `Teacher.html`;
   - нажмите **Сохранить**.
4. Вверху выберите функцию **`setup`** и нажмите **Выполнить**. Google попросит разрешение:
   «Проверить разрешения» → ваш аккаунт → если появится «Google не проверил это приложение» — «Дополнительные настройки» → «Перейти на страницу…» → «Разрешить».
   В таблице появятся листы: Ученики, Прогресс, Попытки, Доска, Настройки.
5. Заполните лист **«Ученики»**: столбец A — класс (8А), столбец B — фамилия и имя (Сейткали Айдана). По одному ученику в строке.
6. На листе **«Настройки»** в ячейке **B2** замените PIN `1234` на свой. В ячейке **B3** — «да» (проверять учеников по списку) или «нет» (пускать всех).
7. **Развернуть → Новое развертывание** → значок шестерёнки → **Веб-приложение**:
   - Выполнять как: **Я**;
   - У кого есть доступ: **Все**;
   - **Развернуть** → скопируйте URL веб-приложения.

## Ссылки

- Для учеников: URL веб-приложения (можно сделать QR-код).
- Для учителя: тот же URL и в конце `?page=teacher`, например `https://script.google.com/macros/s/…/exec?page=teacher`. Вход по PIN.

## Как пользоваться на уроке

- Ученик вписывает класс и фамилию с именем, система ищет его в списке:
  - нашла → ученик входит под именем точно как в вашем списке. Не важны регистр, порядок слов («Айдана Сейткали» = «Сейткали Айдана»), «е» вместо «ё», латинская «A» в классе;
  - похожее имя (опечатка) → «Может быть, ты — Сейткали Айдана, 8А?» и кнопка «Да, это я»;
  - нет в списке или нет такого класса → не пускает и просит обратиться к учителю.
- Если лист «Ученики» пустой или в B3 стоит «нет», пускаются все, кто вписал класс и имя. Лист «Ученики» ведёте только вы; все вошедшие видны на листе «Прогресс».
- На вкладке «Прогресс» серым видно учеников из списка, которые ещё не вошли.
- На одном компьютере может работать несколько учеников по очереди: каждый входит под своим именем, прогресс у каждого свой.
- Вопрос классу: впишите вопрос или нажмите готовый → «Открыть вопрос». Ответы появляются на вкладке «Доска ответов» через несколько секунд. «Закрыть вопрос» — окно у учеников закроется.
- «Крупно для проектора» увеличивает текст. Фильтр «Класс» показывает один класс.
- **Прогресс**: у каждого ученика столбец «Сейчас на» — уровень и задание практики (например, «B · B2»). Нажмите на имя — откроется разбор ученика.
- **Анализ по классам**: сравнение классов (вошли, «Вспомним» и «Какая функция» с первой попытки, дескрипторы Д1–Д6 в %), где сейчас ученики класса, самооценка, частые ошибки и «Кому нужна помощь».
- **Ученик**: все результаты, дескрипторы, самооценка, ответы на вопросы, все попытки. Кнопка «Сохранить PDF» кладёт отчёт на ваш Google Диск: папка «Урок «Математические функции» — отчёты» → папка класса. В «Анализе» есть кнопка «PDF для каждого ученика класса».
- Класс всегда приводится к одному виду: «8A» и «8А», «8F» и «8Ф» — один класс (латинская буква заменяется русской), и в списке учеников тоже.
- Данные не удаляются: в таблице копятся результаты всех уроков.
- **Физминутка для всех**: кнопка на экране учителя — у всех учеников откроется окно с 4 упражнениями по 15 секунд (глаза, «восьмёрка», кисти рук, потягивание). Ученик может запустить её и сам кнопкой «Физминутка» в уроке.
- **Работа в Excel**: этап 7 — 6 сценариев (по одному на СУММ, ABS, КОРЕНЬ, СТЕПЕНЬ, СУММЕСЛИ и смешанный «Ремонт комнаты»), 48 шагов. Ученик работает в настоящем Excel и вписывает формулу и ответ; на экране учителя — столбец «Excel» и попытки в ленте. Ключ с ответами — файл `Ключ_Excel_сценарии.xlsx`.
- **Домашнее задание**: этап 9 урока, три задания (A, B, C) с той же автопроверкой. Ученик открывает урок дома по той же ссылке и входит под своим именем. На экране учителя — столбец «ДЗ», в ленте попыток — этап «9. Домашнее задание».

## Если поменяли урок

1. Выполните `python3 tools/build_gas.py` — обновится `Lesson.html`.
2. Вставьте новый `Lesson.html` в редактор Apps Script.
3. **Развернуть → Управление развертываниями** → карандаш → Версия: **Новая версия** → Развернуть. Ссылка останется прежней.

## Ограничения

- Если аккаунт школьный (Google Workspace), администратор может разрешать доступ только «пользователям домена». Тогда ученикам без школьного аккаунта страница не откроется — используйте личный аккаунт или попросите администратора.
- У Apps Script есть лимит одновременных запросов. Страница опрашивает сервер раз в 5 секунд — для одного класса (около 30 учеников) этого хватает; несколько классов одновременно могут работать медленнее.
- В таблице хранятся имена учеников. Не открывайте доступ к таблице посторонним.
