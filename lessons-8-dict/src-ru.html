Итог

Словарь: dict

В списке элемент ищут по номеру. Но часто удобнее искать по имени: оценку — по фамилии ученика, цену — по названию товара, перевод — по слову. Для этого в Python есть словарь.

Основные понятия

Словарь (dict)

набор пар «ключ: значение» в фигурных скобках: {"хлеб": 250, "сыр": 1800}.

Ключ

то, по чему ищут: название, имя, номер. Ключи в словаре не повторяются.

Значение

то, что хранится под ключом: число, строка, список — что угодно.

Пара

ключ вместе со значением. Словарь можно собрать из списка или кортежа пар.

Преобразование

превращение списков и кортежей в словарь: dict(pairs), dict(zip(keys, values)).

Коллекции Python

список, кортеж, множество и словарь. Словарь — единственный, где элемент ищут не по номеру, а по ключу.

dict — словарь

Простыми словами: словарь — как телефонная книга: находишь имя и сразу видишь номер. Имя — ключ, номер — значение.

Где применяется

  • Цены в магазине: prices = {"хлеб": 250, "сыр": 1800}
  • Оценки в журнале: marks = {"Айдана": 5, "Тимур": 4}
  • Словарик переводов: words = {"яблоко": "apple", "вода": "water"}

Не подходит: если важен только порядок элементов и нет «имён» — хватит списка.

Как записать: d = {"ключ": значение, …}, d = {}

Определение

Словарь (dict) — изменяемая коллекция пар «ключ: значение». Пары записывают в фигурных скобках через запятую, между ключом и значением ставят двоеточие. По ключу словарь быстро находит значение.

Синтаксис

имя = {ключ1: значение1, ключ2: значение2, …}

Пустой словарь: d = {} или d = dict().

Примеры

Кнопка «Открыть в редакторе» переносит пример в редактор ниже — там его можно изменить и запустить.

Свойства словаря

  • Изменяем: пары можно добавлять, менять и удалять.
  • Ключи не повторяются: если ключ записан дважды, остаётся последнее значение.
  • Порядок сохраняется: пары хранятся в том порядке, в каком их добавили (так в Python начиная с версии 3.7; в более старых версиях порядок не гарантировался).

Важно знать

  • Ключом может быть только неизменяемое значение: строка, число или кортеж. Список ключом быть не может.
  • Значением может быть что угодно, даже список или другой словарь.
  • Номеров у словаря нет: d[0] ищет ключ 0, а не первую пару.
Попробуй сам

Запомни: словарь — фигурные скобки и пары ключ: значение. Ключи не повторяются.

d[key], d.get(key), key in d — доступ по ключу

Простыми словами: чтобы найти значение, называют ключ: «сколько стоит хлеб?» — prices["хлеб"].

Где применяется

  • Цена товара: prices["сыр"]
  • Оценка ученика, если его может не быть в журнале: marks.get("Дана", 0)
  • Есть ли слово в словарике: "вода" in words

Не подходит: квадратные скобки для ключа, которого нет, — ошибка KeyError. Тогда используют get.

Как записать: d["хлеб"], d.get("хлеб", 0), "хлеб" in d, len(d)

Определение

d[key] возвращает значение по ключу; если ключа нет — ошибка KeyError. Метод d.get(key, default) возвращает значение, а если ключа нет — значение по умолчанию (без него — None). Оператор key in d проверяет, есть ли такой ключ. len(d) — количество пар.

Синтаксис

словарь[ключ] · словарь.get(ключ, по_умолчанию)

Примеры

Важно знать

  • in проверяет ключи, а не значения.
  • get не меняет словарь, только читает.
Попробуй сам

Запомни: значение — по ключу: d[key]. Ключа может не быть — d.get(key, 0).

Изменение словаря: добавить, заменить, удалить

Простыми словами: записать в телефонную книгу нового человека, исправить номер, вычеркнуть строку — всё это делают по имени, то есть по ключу.

Где применяется

  • Новый товар или новая цена: prices["чай"] = 900
  • Обновить сразу несколько цен: prices.update({"хлеб": 260, "сок": 700})
  • Товар закончился: prices.pop("сыр")

Не подходит: удалить ключ, которого нет, через del или pop без запасного значения — ошибка KeyError.

Как записать: d[key] = value, d.update(other), d.pop(key), del d[key], d.clear()

Определение

Присваивание d[key] = value заменяет значение, если ключ есть, и добавляет новую пару, если ключа нет. update(other) добавляет или заменяет сразу несколько пар. pop(key) удаляет пару и возвращает значение, del d[key] удаляет пару, clear() очищает словарь, popitem() удаляет последнюю добавленную пару.

Синтаксис

словарь[ключ] = значение

Примеры

Важно знать

  • Одна и та же запись d[key] = value и добавляет, и заменяет — всё зависит от того, есть ли ключ.
  • pop(key, 0) с запасным значением не выдаёт ошибку, если ключа нет.
  • Копия словаря — d.copy() или dict(d); запись b = d копию не создаёт: это второе имя того же словаря.
  • del d без ключа удаляет весь словарь вместе с именем: после этого print(d) выдаст NameError.
Попробуй сам

Запомни: d[key] = value — добавить или заменить; pop и del — удалить.

Перебор: keys(), values(), items()

Простыми словами: можно пройти по словарю и прочитать только имена, только номера или пары «имя — номер» сразу.

Где применяется

  • Вывести весь прайс-лист: for name, price in prices.items():
  • Сумма всех цен: sum(prices.values())
  • Список учеников из журнала: list(marks.keys())

Не подходит: добавлять и удалять ключи во время перебора словаря нельзя — будет ошибка.

Как записать: for k in d:, for k, v in d.items():

Определение

Цикл for k in d перебирает ключи. d.keys() — все ключи, d.values() — все значения, d.items() — все пары в виде кортежей (ключ, значение). Пары удобно сразу распаковать: for k, v in d.items().

Синтаксис

for ключ, значение in словарь.items():

Примеры

Важно знать

  • items() даёт кортежи — так словарь превращается обратно в пары: list(d.items()).
  • keys(), values(), items() — «виды» словаря: если словарь изменить, вид сразу покажет изменения.
  • Значения можно перебрать и через ключи: for k in d: print(d[k]).
  • sum, max, min работают с d.values().
Попробуй сам

Запомни: keys() — ключи, values() — значения, items() — пары.

Словарь-счётчик

Простыми словами: как подсчёт голосов на доске: для каждого кандидата своя строка, и при каждом голосе к ней прибавляют палочку.

Где применяется

  • Сколько каких оценок в журнале: count[m] = count.get(m, 0) + 1
  • Сколько раз встречается каждое слово: freq[w] = freq.get(w, 0) + 1
  • Итог продаж по товарам: total[name] = total.get(name, 0) + q

Не подходит: если нужно посчитать только одно значение, хватит count() у списка.

Как записать: d[x] = d.get(x, 0) + 1

Определение

Словарь-счётчик хранит для каждого значения, сколько раз оно встретилось. Перебирают данные и для каждого элемента x увеличивают d[x] на 1. Запись d.get(x, 0) даёт 0, если x встречается впервые.

Синтаксис

for x in данные: d[x] = d.get(x, 0) + 1

Примеры

Важно знать

  • Без get первая же запись d[x] += 1 для нового x даст KeyError.
  • Счётчик сохраняет порядок первого появления значений.
Попробуй сам

Запомни: счётчик — d[x] = d.get(x, 0) + 1.

Вложенные словари

Простыми словами: словарь в словаре — как классный журнал, где у каждого ученика своя карточка с полями «имя», «год рождения», «оценки».

Где применяется

  • Данные об учениках класса: pupils["u2"]["имя"]
  • Товары с ценой и остатком: stock["хлеб"]["цена"]

Не подходит: если у объекта одно значение, вложенный словарь не нужен.

Как записать: d[внешний_ключ][внутренний_ключ]

Определение

Вложенный словарь — словарь, значения которого тоже словари. Чтобы получить значение, ключи пишут по порядку: сначала внешний, потом внутренний. Вложенный словарь можно записать сразу или собрать из готовых словарей.

Синтаксис

словарь[ключ1][ключ2]

Примеры

Важно знать

  • Перебор вложенного словаря — цикл в цикле: for k, obj in d.items(): и внутри for y in obj:.
  • Если внутреннего ключа нет, будет KeyError, как и у обычного словаря.

Списки и кортежи → словарь

Простыми словами: есть два столбика — фамилии и оценки. Преобразование в словарь склеивает их построчно: каждая фамилия получает свою оценку.

Где применяется

  • Список пар → словарь: dict([("хлеб", 250), ("сыр", 1800)])
  • Два списка: ключи и значения: dict(zip(names, marks))
  • Все ключи с одним значением: dict.fromkeys(names, 0)
  • Обратно в список пар: list(d.items())

Не подходит: dict от списка, где элементы не пары, — ошибка: каждый элемент должен состоять ровно из двух частей.

Как записать: dict(pairs), dict(zip(keys, values)), dict.fromkeys(keys, value)

Определение

Функция dict() создаёт словарь из последовательности пар: списка или кортежа, где каждый элемент — кортеж или список из двух значений (ключ и значение). Функция zip(a, b) соединяет два списка или кортежа поэлементно в пары: первый с первым, второй со вторым. Поэтому dict(zip(keys, values)) делает словарь из отдельных списков ключей и значений. dict.fromkeys(keys, value) создаёт словарь, где у всех ключей одно и то же значение.

Синтаксис

dict(список_пар) · dict(zip(ключи, значения)) · dict.fromkeys(ключи, значение)

Примеры

Обратное преобразование

list(d.keys()) — список ключей, list(d.values()) — список значений, list(d.items()) — список кортежей-пар, tuple(d) — кортеж ключей.

Важно знать

  • Если списки в zip разной длины, лишние элементы длинного списка отбрасываются.
  • Если ключи повторяются, в словаре остаётся последнее значение.
  • Словарь можно собрать и в цикле: for k, v in pairs: d[k] = v.

Запомни: пары → dict(pairs); два списка → dict(zip(keys, values)); обратно → list(d.items()).

Практика

Сначала разминка на доступ по ключу, потом задания трёх уровней — от простого к сложному. Задания бывают четырёх видов: «Что выведет программа?», «Допиши», «Найди ошибку» и «Напиши программу». Следующее задание открывается, когда решено предыдущее. Программу проверяют и на других данных.

Практическая работа

Три небольших проекта. В каждом нужно написать программу целиком: собрать словарь из введённых данных и обработать его. Выбери проект — можно сделать все три. Программу проверяют на нескольких наборах данных.

Олимпиадные задачи

Задачи в стиле олимпиад и сайта Codeforces. У каждой задачи — условие, формат входных и выходных данных и примеры. Нажми «Отправить»: программа пройдёт все тесты, а ты получишь вердикт. Если тест не пройден, увидишь его входные данные, правильный ответ и вывод своей программы.

Как в олимпиадах читают и выводят список. Числа часто записаны в одной строке через пробел:

n = int(input())                     # первая строка: количество чисел
a = list(map(int, input().split()))  # вторая строка: все числа — в список
print(*a)                            # вывести элементы через пробел
x, y = map(int, input().split())     # два числа в строке — сразу в две переменные
name, score = input().split()        # строка «имя балл» — в две переменные

input().split() разрезает строку по пробелам, map(int, …) превращает каждую часть в число, list(…) собирает числа в список. print(*a) выводит элементы списка через пробел, без скобок.

Тест: впиши пропущенное

В каждой программе пропущено одно или два слова. Впиши их и нажми «Проверить» или Enter. Во всех заданиях, где не сказано иначе, словарь такой:

prices = {"хлеб": 250, "молоко": 450, "сыр": 1800}
