Екі өлшемді массивтерДвумерные массивы

1. Екі өлшемді массив деген не?1. Что такое двумерный массив?

Кәдімгі (бір өлшемді) тізім — бір қатарға тізілген сандар: [5, 8, 2]. Ал екі өлшемді массив — бұл кесте: оның жолдары мен бағандары бар. Өмірдегі мысалдар: сынып журналы (жол — оқушы, баған — күн), шахмат тақтасы, кинотеатрдағы орындар, Excel кестесі.

Обычный (одномерный) список — числа в один ряд: [5, 8, 2]. А двумерный массив — это таблица: у неё есть строки и столбцы. Примеры из жизни: классный журнал (строка — ученик, столбец — дата), шахматная доска, места в кинотеатре, таблица Excel.

Python-да екі өлшемді массив — тізімдердің тізімі: үлкен тізімнің әр элементі — бір жол, ал жол — кәдімгі тізім. Мұндай кестені матрица деп те атайды.

В Python двумерный массив — это список списков: каждый элемент большого списка — одна строка, а строка — обычный список. Такую таблицу ещё называют матрицей.

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6]]
print(a)
print(len(a))
print(len(a[0]))
НәтижеВывод
[[1, 2, 3], [4, 5, 6]]
2
3

a — 2 жолдан және 3 бағаннан тұратын кесте. len(a) — жолдар саны (2), len(a[0]) — бірінші жолдың ұзындығы, яғни бағандар саны (3).

a — таблица из 2 строк и 3 столбцов. len(a) — число строк (2), len(a[0]) — длина первой строки, то есть число столбцов (3).

2. Элементке қалай қол жеткіземіз: a[i][j]2. Как обратиться к элементу: a[i][j]

Элемент екі индекспен алынады: алдымен жолдың нөмірі i, содан кейін бағанның нөмірі j. Нөмірлеу, кәдімгі тізімдегідей, 0-ден басталады.

Элемент берут по двум индексам: сначала номер строки i, затем номер столбца j. Нумерация, как в обычном списке, начинается с 0.

a[1] — бүкіл бір жол (тізім). a[1][2] — сол жолдың 2-элементі. Элементті кәдімгі айнымалы сияқты өзгертуге болады: a[0][1] = 20.

a[1] — целая строка (список). a[1][2] — элемент 2 в этой строке. Элемент можно изменять, как обычную переменную: a[0][1] = 20.

Есте сақтаңыз: бірінші индекс — жол (жоғарыдан төмен), екінші — баған (солдан оңға). «Алдымен жол, сосын баған».

Запомните: первый индекс — строка (сверху вниз), второй — столбец (слева направо). «Сначала строка, потом столбец».

3. Кестені экранға шығару3. Вывод таблицы на экран

print(a) кестені жақшалармен бір жолға шығарады — оқуға ыңғайсыз. Кестені жол-жолмен шығару үшін цикл қолданамыз. Ең оңай тәсіл — print(*row): жұлдызша жолдың элементтерін бос орын арқылы шығарады.

print(a) выводит таблицу в одну строку со скобками — читать неудобно. Чтобы вывести таблицу по строкам, используем цикл. Самый простой способ — print(*row): звёздочка выводит элементы строки через пробел.

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6]]
for row in a:
    print(*row)
НәтижеВывод
1 2 3
4 5 6

Индекстер арқылы — ішкі цикл (цикл ішіндегі цикл): сыртқы цикл жолдарды, ішкі цикл бағандарды аралайды.

Через индексы — вложенный цикл (цикл внутри цикла): внешний цикл перебирает строки, внутренний — столбцы.

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6]]
for i in range(len(a)):
    for j in range(len(a[i])):
        print(a[i][j], end=" ")
    print()
НәтижеВывод
1 2 3 
4 5 6

end=" " — сандарды бір жолға бос орын арқылы шығарады, ал бос print() — келесі жолға көшіреді.

end=" " выводит числа в одну строку через пробел, а пустой print() переводит на новую строку.

4. Кестені пернетақтадан енгізу4. Ввод таблицы с клавиатуры

Есептерде деректер әдетте былай беріледі: бірінші жолда n (жолдар саны) және m (бағандар саны), содан кейін n жол, әр жолда m сан. Әр жолды input().split() арқылы оқып, санға айналдырып, кестеге қосамыз.

В задачах данные обычно даются так: в первой строке n (число строк) и m (число столбцов), затем n строк по m чисел. Каждую строку читаем через input().split(), превращаем в числа и добавляем в таблицу.

ПрограммаПрограмма
n, m = map(int, input().split())
a = []
for i in range(n):
    row = list(map(int, input().split()))
    a.append(row)
print(a)
КірісВвод
2 3
1 2 3
4 5 6
НәтижеВывод
[[1, 2, 3], [4, 5, 6]]

Қысқа жазу (тізім генераторы): a = [list(map(int, input().split())) for i in range(n)] — дәл осыны істейді.

Короткая запись (генератор списка): a = [list(map(int, input().split())) for i in range(n)] — делает то же самое.

5. Нөлдерден тұратын кестені құру5. Создание таблицы из нулей

Кестені өзіміз толтырғымыз келсе, алдымен n жол, m бағаннан тұратын «бос» (нөлдер) кесте жасаймыз:

Если таблицу нужно заполнить самим, сначала создаём «пустую» таблицу (из нулей) из n строк и m столбцов:

ПрограммаПрограмма
n, m = 3, 4
a = [[0] * m for i in range(n)]
a[1][2] = 7
for row in a:
    print(*row)
НәтижеВывод
0 0 0 0
0 0 7 0
0 0 0 0

Назар аударыңыз — жиі қате! [[0] * m] * n деп жазуға болмайды: онда барлық жол — бір ғана тізім, біреуін өзгертсеңіз, барлығы өзгереді:

Внимание — частая ошибка! Нельзя писать [[0] * m] * n: тогда все строки — один и тот же список, и изменение одной меняет все:

ПрограммаПрограмма
a = [[0] * 4] * 3
a[1][2] = 7
for row in a:
    print(*row)
НәтижеВывод
0 0 7 0
0 0 7 0
0 0 7 0

Сумма всех элементов — вложенный цикл и переменная-накопитель:

Сумма каждой строки — sum(row). Сумма столбца — номер столбца j фиксируем, а i перебирает все строки:

Шарт бойынша қосынды. Барлық элементті емес, тек шартқа сәйкес келетіндерін қосамыз: ішкі циклдың ішіне if қоямыз. Санның жұп екенін x % 2 == 0 (2-ге қалдықсыз бөлінеді), тақ екенін x % 2 != 0, k-ға бөлінетінін x % k == 0 тексереді.

Сумма по условию. Складываем не все элементы, а только подходящие под условие: внутрь вложенного цикла ставим if. Число чётное — x % 2 == 0 (делится на 2 без остатка), нечётное — x % 2 != 0, делится на k — x % k == 0.

Жұп элементтердің қосындысы (яғни 2-ге бөлінетіндердің қосындысы):

Сумма чётных элементов (то есть делящихся на 2):

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6]]
s = 0
for row in a:
    for x in row:
        if x % 2 == 0:
            s = s + x
print(s)

Сумма элементов, делящихся на число k (например, на 3):

Бір циклда бірнеше қосынды және санау. Жұп және тақ элементтердің қосындысын да, санын да бір рет аралап табуға болады:

Несколько сумм и подсчёт за один цикл. Сумму и количество чётных и нечётных элементов можно найти за один проход:

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6]]
sj, st = 0, 0
kj, kt = 0, 0
for row in a:
    for x in row:
        if x % 2 == 0:
            sj = sj + x
            kj = kj + 1
        else:
            st = st + x
            kt = kt + 1
print("juptar:", sj, kj)
print("taqtar:", st, kt)
НәтижеВывод
juptar: 12 3
taqtar: 9 3

Жұптардың қосындысы 12, саны 3; тақтардың қосындысы 9, саны 3. Теріс сандар: Python-да -4 % 2 == 0 және -3 % 2 == 1, сондықтан шарттар теріс сандар үшін де дұрыс жұмыс істейді.

Сумма чётных 12, их 3; сумма нечётных 9, их 3. Отрицательные числа: в Python -4 % 2 == 0 и -3 % 2 == 1, поэтому условия правильно работают и для отрицательных чисел.

Ең үлкен элемент және оның орны:

Наибольший элемент и его место:

ПрограммаПрограмма
a = [[3, 9, 2],
     [7, 1, 9]]
mx = a[0][0]
bi, bj = 0, 0
for i in range(2):
    for j in range(3):
        if a[i][j] > mx:
            mx = a[i][j]
            bi, bj = i, j
print(mx, bi, bj)

7. Квадрат матрица және диагональдар7. Квадратная матрица и диагонали

Жолдар мен бағандар саны тең болса (n × n), матрица квадрат деп аталады. Бас диагональ — жол нөмірі баған нөміріне тең элементтер: a[i][i]. Қосалқы диагональ — a[i][n - 1 - i].

Если число строк и столбцов одинаково (n × n), матрица называется квадратной. Главная диагональ — элементы, у которых номер строки равен номеру столбца: a[i][i]. Побочная диагональ — a[i][n - 1 - i].

Бас диагональ: a[0][0], a[1][1], a[2][2] → 1, 5, 9Главная диагональ: a[0][0], a[1][1], a[2][2] → 1, 5, 9

ПрограммаПрограмма
a = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]
n = 3
s1 = 0
s2 = 0
for i in range(n):
    s1 = s1 + a[i][i]
    s2 = s2 + a[i][n - 1 - i]
print(s1, s2)

8. Жиі кездесетін қателер8. Частые ошибки

  • IndexError: list index out of range — индекс тым үлкен. Есте сақтаңыз: соңғы жол — n - 1, соңғы баған — m - 1.
  • Жол мен бағанды шатастыру — a[j][i] емес, a[i][j]: алдымен жол, сосын баған.
  • [[0] * m] * n — барлық жол бір тізім болып шығады. Дұрысы: [[0] * m for i in range(n)].
  • Сандарды int-ке айналдыруды ұмыту — input().split() мәтін береді; map(int, …) қажет.
  • Кестені print(a) арқылы шығару — жауап жақшалармен шығады. Жол-жолмен шығарыңыз: print(*row).
  • IndexError: list index out of range — индекс слишком большой. Помните: последняя строка — n - 1, последний столбец — m - 1.
  • Путаница строки и столбца — не a[j][i], а a[i][j]: сначала строка, потом столбец.
  • [[0] * m] * n — все строки оказываются одним списком. Правильно: [[0] * m for i in range(n)].
  • Забыли превратить в int — input().split() даёт строки; нужен map(int, …).
  • Вывод таблицы через print(a) — ответ выйдет со скобками. Выводите по строкам: print(*row).
