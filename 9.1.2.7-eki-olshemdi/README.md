# 9.1.2.7 — Екі өлшемді массивтер / Двумерные массивы (веб-ресурс)

`web/standalone/eki-olshemdi-9.1.2.7.html` — бір файл; Python 3 (Skulpt, MIT) файлдың ішінде, интернет қажет емес (тек поштаға жіберу үшін).

- **1. Теория** (уақыт жүрмейді): екі өлшемді массив деген не; a[i][j]; кестені шығару (ішкі цикл); енгізу;
  нөлдер кестесі және `[[0]*m]*n` қатесі; типтік есептер (қосынды, жол/баған қосындысы, максимум және орны);
  квадрат матрица, бас және қосалқы диагональ; жиі қателер; шпаргалка. Мысалдардың нәтижесі нағыз Python-да алынған
  (`web/tools/build-theory.py`). Жұмыс кезінде теория «📖 Теория» батырмасымен кез келген уақытта ашылады.
- **2. Есептер** — 10 олимпиадалық есеп: A (1–4): элементтер қосындысы, әр жолдың қосындысы, ең үлкен/кіші элемент, диагональ;
  B (5–7): әр бағанның қосындысы, ең үлкен элементтің орны, транспонирлеу; C (8–10): екі жолды ауыстыру, симметриялы матрица, «жылан».
  Әр есеп 8 тестте тексеріледі (2 мысал + 6 жасырын), 1 балл, ең көбі 10. Әр оқушының сандары әртүрлі.
- Толық экран, бұзушылықтар (2 ескерту, 3-інде аяқталады), ҚАЗ/РУС, «⌨ Латиница», нәтиже бетінде талдау.
- Нәтижелер мұғалімнің поштасына: `web/server/Code.gs` (Apps Script, жеке жоба керек — APP = eki-olshemdi-9.1.2.7);
  `web/config.js`: `RESULTS_URL`, `CLASSES`, `WORK_MIN` (40).
- Кілтті тексеру: `python3 web/tools/check.py`; жинау: `python3 web/tools/build-theory.py && node web/tools/build-standalone.js`.
