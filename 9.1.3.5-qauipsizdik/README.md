# 9.1.3.5–9.1.3.6 — Желідегі қауіпсіздік. Желілік этикет

Веб-ресурс: `web/standalone/qauipsizdik-9.1.3.5.html` — один файл, без интернета. Интерфейс на казахском и русском
(кнопки ҚАЗ / РУС в любой момент, ответы сохраняются), по умолчанию казахский.

Осознанное чтение теории (INSERT): под каждым абзацем теории (список и таблица — один абзац, всего 15) ученик ставит
пометку ✓ «Білемін», + «Жаңа ақпарат», − «Басқаша ойлағанмын», ? «Түсінбедім»; пока все абзацы не отмечены, кнопка
«Жұмысқа өту» закрыта. На странице результата — число пометок и список абзацев с «?» и «−» (что объяснить ещё раз).
Теория — 6 разделов, 6-й — «Саналы оқу: факт пен пікір».

Ход работы: начальная страница → теория (без таймера) → инструкция → 15 заданий (40 минут) → балл и разбор каждого задания.

Задания (у каждого ученика свой набор: элементы берутся из банков, варианты ответов перемешиваются):
1. Сәйкестендіру — термин ↔ определение (5 из 10 терминов).
2. Бос орынды толтыру — пропуски с выбором слова (1 из 2 текстов: правила безопасности / агрессия и нетикет).
3. Ақиқат / Жалған — 6 утверждений из 12, в разборе — пояснение.
4. Алаяқтың хатын әшкере ету — нажать на подозрительные строки письма или сообщения (1 из 2), 6 признаков.
5. Сілтемені тексеру — официальный сайт или поддельный (поддомены, замена буквы, домен-приманка).
6. Топтастыру — безопасное / опасное действие (8 из 12).
7. Ретке келтіру — пароли от слабого к надёжному.
8. Чат-тренажёр — диалог с «незнакомцем в игре» или «службой безопасности банка», 3 шага.
9. Нетикетті кім бұзды? — нажать на сообщения группового чата, нарушающие нетикет (5 из 10).
10. Саналы оқу: мәтінмен жұмыс — короткая история (1 из 2) и 4 вопроса трёх уровней: найти информацию, интерпретировать
    (почему поверил, лучший заголовок), оценить (какой вывод следует из текста).
11. Факт пе, пікір ме? — 6 предложений разделить на факты и мнения.
12–13. Жағдаят талдау (9.1.3.6) — 2 ситуации из 3, отметить все верные последствия.
14. Түзет — переписать грубое сообщение вежливо (письменный ответ, 3 критерия).
15. Пайымда (9.1.3.6) — рассуждение о ситуации в 4–5 предложениях (письменный ответ, 4 критерия).
Во время заданий есть кнопка «📖 Теорияға оралу» (таймер не останавливается), возврат — «← Тапсырмаларға оралу».

Баллы: 1 балл за каждый верный пункт; в заданиях «найди / отметь» лишняя отметка уменьшает балл (ниже нуля не бывает),
поэтому «отметить всё» не даёт максимума. Максимум — около 72 баллов (зависит от варианта).

Правила, как в 8.1.4.3: вся работа (и теория) в полноэкранном режиме; выход из него, смена вкладки или окна,
перезагрузка — нарушение: два раза предупреждение, на третий работа завершается. Результат виден 4 минуты,
затем открывается начальная страница; новая работа — без пароля. Настройки — `web/config.js`.

## Дополнительный уровень (★) — для тех, кто закончил раньше
После сдачи на странице результата есть кнопка «★ Тағы сынап көр» — 2 попытки по 15 минут (`BONUS_ATTEMPTS`, `BONUS_MIN`).
Баллы не входят в основную оценку, показываются звёздочками (лучшая попытка). В каждой попытке свои задания:
1. письмо/SMS со скрытыми признаками (поддельный адрес за текстом ссылки, «.pdf.exe», домен-приманка, номер из SMS);
2. сложные ссылки («@», «?», дефис, похожие буквы/цифры, поддомены);
3. «Түзет» и 4. «Пайымда» — с другими ситуациями, чем в основной работе и в другой попытке.
Ответы 3–4 учитель видит на странице результата вместе с оценкой по каждому критерию.

### Проверка письменных ответов
1. Сразу — автоматическая проверка без интернета: грубые слова, капс, «!!!», вежливые слова, ключевые слова по каждому
   критерию, число предложений и слов, копирование текста задания. К каждому невыполненному критерию — подсказка 💡.
2. Если в настройках есть ключ (`AI_KEY` в самом начале файла) и есть интернет — ответ проверяет внешний ИИ
   (Google Gemini API, бесплатный тариф): по каждому критерию «да/нет» с комментарием и короткий отзыв на языке ученика.
   Ключ учитель получает бесплатно на aistudio.google.com («Get API key», нужен Google-аккаунт 18+) и вставляет в файл
   Блокнотом. ИИ проверяет ОДИН раз в конце, все письменные ответы ученика одним запросом: после второй попытки,
   или по кнопке «Аяқтау және ЖИ-ге тексерту» (оставшаяся попытка тогда закрывается), или сам за минуту до закрытия
   страницы результата. После каждой попытки ученик сразу видит автоматическую оценку с подсказками.
   При лимите бесплатного тарифа (429) страница ждёт и повторяет, если модель
   недоступна (404) — пробует следующую из `AI_MODELS`. Нет связи — остаётся автоматическая оценка.
   В ИИ уходит только текст ответа, без имени. На бесплатном тарифе Google может использовать присланные тексты
   для улучшения своих продуктов. Ключ виден в файле — это бесплатный ключ, деньги с него не списываются.
3. Если ученик не согласен — учитель нажимает «✎ Мұғалім: балды өзгерту», вводит пароль `TEACHER_PIN` (1212)
   и ставит свой балл, он заменяет автоматический/ИИ. На странице результата кнопок «новая работа» и «теория» нет; новая работа открывается сама через 4 минуты.
