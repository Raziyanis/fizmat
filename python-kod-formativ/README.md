# Формативтік жұмыс: оқушы Python-да код жазады / Формативная работа: ученик пишет код на Python

- `standalone/python-kod-formativ-kz.html` (қазақша) және `standalone/python-kod-formativ-ru.html` (орысша) — дайын файлдар.
  Бір файл, интернет пен сервер қажет емес: Python интерпретаторы (Skulpt, MIT лицензиясы, `vendor/LICENSE`) файлдың ішінде.
- 10 есеп: шарт (3), for циклі (2), while циклі (1), тізім (2), жиын (2). Әр оқушының есеп нұсқасы, сандары және тестілері әртүрлі.
- Әр есепте 8 тест (2 мысал көрінеді + 6 жасырын). 8 тесттің бәрінен өтсе — 1 балл, ең көбі 10.
- Балл жұмыс аяқталғанда соңғы кодтар бойынша автоматты есептеледі. Толық экраннан шығу, басқа терезеге ауысу,
  бетті жабу немесе қайта жүктеу — жұмыс бірден аяқталады (жабылса, балл файл қайта ашылғанда шығады).
- Нәтиже экранында: балл, әр есептің шарты, оқушының коды, үлгі шешім және бірінші қате тест. 5 минуттан кейін жасырылады.
- Баптаулар `config.js`: құпиясөз (2026), уақыт (40 минут), нәтиженің көріну уақыты. Жинау: `node tools/build-standalone.js`.
- Кілтті тексеру: `python3 tools/check-tasks.py` — үлгі шешімдер нағыз Python-да барлық тестте орындалады (300 нұсқа).
- Қауіпсіздік: оқушы коды тек `sys`, `math`, `random` модульдерін қолдана алады; `document`, `jseval` өшірілген,
  сондықтан код бетті немесе баллды өзгерте алмайды. Шексіз цикл 1 секундтан кейін тоқтатылады.
