📘 Что такое множество

Множество (set) - коллекция, в которой каждый элемент встречается только один раз.

🎯
Только уникальныеПовторы удаляются автоматически: set([1, 2, 2]) → {1, 2}
🔀
Нет порядка и индексовНельзя написать s[0] - у элементов нет номеров.
🧊
Неизменяемые элементыЧисла, строки, кортежи - можно. Список внутри множества - нельзя.

Как создать множество

s = {3, 1, 2}          # в фигурных скобках
s = set([1, 2, 2])    # из списка → {1, 2}
s = set('мама')       # из строки → {'м', 'а'}
s = set()             # пустое множество
d = {}                # ⚠ это НЕ множество, а пустой словарь (dict)!

⚖️ Список и множество

    🔗 Операции над множествами
    
      
    Методы из этой части работают сразу с двумя множествами: a и b. Одни возвращают новое множество, другие - True или False, а методы с _update изменяют само a.
    
      
    
        
    🆕
    Новое множествоunion, intersection, difference, symmetric_difference - a и b не меняются.
    
        
    ❓
    True или Falseissubset, issuperset, isdisjoint - только проверяют.
    
        
    ✏️
    Изменяет adifference_update, intersection_update, symmetric_difference_update - результат записывается прямо в a.
    
      
    
      
    Методы и операторы для a = {1, 2, 3, 4}, b = {3, 4, 5, 6}
    
      
    
        
    
          
    МетодОператорЧто получаемРезультат
    
          
            
    a.union(b)a | bвсе элементы a и b (объединение){1, 2, 3, 4, 5, 6}
    
            
    a.intersection(b)a & bобщие элементы (пересечение){3, 4}
    
            
    a.difference(b)a - bэлементы a, которых нет в b (разность){1, 2}
    
            
    a.symmetric_difference(b)a ^ bэлементы только одного из множеств{1, 2, 5, 6}
    
            
    a.issubset(b)a <= bвсе ли элементы a есть в bFalse
    
            
    a.issuperset(b)a >= bсодержит ли a все элементы bFalse
    
            
    a.isdisjoint(b)-нет ли общих элементовFalse
    
            
    a.difference_update(b)a -= bудаляет из a элементы ba → {1, 2}
    
            
    a.intersection_update(b)a &= bоставляет в a только общие с b элементыa → {3, 4}
    
            
    a.symmetric_difference_update(b)a ^= bоставляет в a элементы только одного из множествa → {1, 2, 5, 6}
