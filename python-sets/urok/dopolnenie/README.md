# Дополнение к файлам урока «Методы множества»

`fayl-uchenika.html` и `fayl-uchitelya.html` получены из исходных файлов скриптом `patch.py`:

- этап 2 «Тема»: карточки методов списка и загадка, после разгадки показываются тема, цель и результаты;
- новая тема разделена на два этапа: 3 «Новая тема» (шаги 1–12) и 4 «Операции» (шаги 13–24);
- в конце каждой части задание на сопоставление «метод — описание» (8 и 10 пар, 3 и 4 минуты);
- номера остальных этапов сдвинуты на один (5 «Понимание» … 9 «Домашнее»), в том числе в таблице «Где достигается цель»;
- все новые тексты на русском и казахском.

Код.gs (Apps Script) не менялся: задания на сопоставление проверяются в браузере и на сервер не отправляются.

Пересборка: `python3 patch.py <папка с addon.js> <исходный файл ученика> <исходный файл учителя> <новый файл ученика> <новый файл учителя>`.
