# Урок 9.2.5.2: методы множества (set) · Жиын әдістері

Цель обучения 9.2.5.2: применять методы, используемые для множеств (9 класс).
Урок полностью двуязычный: переключатель **РУС / ҚАЗ** в шапке переводит все этапы, задания, разборы и подсказки.

| Файл | Для кого |
|---|---|
| `fayl-uchenika.html` | ученик: проходит урок и решает задачи |
| `fayl-uchitelya.html` | учитель: показывает урок на проекторе, разбирает задания, вызывает учеников наугад |
| `src/content.py` | всё содержание урока на двух языках |
| `src/methods.py`, `src/venn.js`, `src/venn.css` | слайды о каждом методе и отрисовка диаграмм Венна |
| `Код.gs` | сервер (Google Apps Script): жауаптарды кестеге жазады және мұғалім экранына береді |
| `src/server.py` | файлдарды серверге қосатын өзгерістер |
| `src/build.py` | сборщик: вставляет содержание в шаблон и проверяет все примеры кода реальным Python |

Файлы самостоятельные: Python (Pyodide) встроен, интернет не нужен. Открываются двойным щелчком в браузере.

## Этапы

1. **Повторение (список и кортеж)** — 15 заданий «что выведет программа», проверка сразу после ответа.
2. **Тема** — цель, ожидаемые результаты по уровням, где какая часть цели отрабатывается и проверяется.
3. **Новая тема** — 24 шага «вопрос классу → ответ с примером»:
   - шаги 1–3: свойства множества, отсутствие индексов, `set()` и `{}`;
   - шаг 4: карта всех 17 методов множества;
   - шаги 5–11: каждый метод отдельно — `add`, `update`, `remove`, `discard`, `pop`, `clear`, `copy`
     (как записать, что делает, меняет ли множество, что возвращает, особый случай, сравнение со списком);
   - шаг 12: проверка `in`;
   - шаги 13–23: методы, которые есть только у множества, на диаграммах Венна (результат закрашен):
     `union`, `intersection`, `difference`, `symmetric_difference`, их версии `*_update`,
     `issubset`, `issuperset`, `isdisjoint`;
   - шаг 24: справочник, сравнительная таблица «список — кортеж — множество» и частые ошибки.
4. **Понимание** — 8 заданий на 10 баллов (верно/неверно, пропуск, выбор, сопоставление).
5. **Практика · ФО** — 10 задач по 1 баллу, каждая на свой метод множества: `set()`+`len`, `add`, `update`,
   `remove`, `discard`, `in`, `union`, `intersection`, `difference`, `symmetric_difference`;
   дополнительные: `issubset`, `isdisjoint`, несколько операций сразу, множество «уже видели».
   Каждое решение проверяется на 4 наборах данных.
6. **Список, кортеж или множество?** — 9 жизненных ситуаций.
7. **Рефлексия** и 8. **Домашнее задание**.

Класс: «9 класс», 11 учеников (список из присланной таблицы).

## Нәтижелерді мұғалімге жіберу: `Код.gs`

`Код.gs` — сабақтың сервері (Google Apps Script). Оқушы файлы әр жауапты осы серверге жібереді,
ол жауапты Google-кестеге жазады, ал мұғалім файлы кестені әр 5–30 секунд сайын өзі оқып,
бәрін экранға шығарады: тест кестесі (кім тапсырды, кім әлі шешуде, қай тапсырмада тұр),
тапсырмалар бойынша талдау, «Түсіну», «Практика» (оқушылардың бағдарламаларымен), «Таңдау»,
рефлексия, мұғалім мен оқушының хат алмасуы. Баллдарды мұғалім файлының өзі есептейді.

### Орнату (бір рет, 5 минут)

1. <https://script.google.com> → **Жаңа жоба** (Новый проект).
2. Ішіндегі мәтінді өшіріп, `Код.gs` файлының бүкіл мазмұнын қойыңыз, сақтаңыз (Ctrl+S).
3. Жоғарыдан `setup` функциясын таңдап, **Іске қосу** (Выполнить) басыңыз, рұқсат беріңіз.
   Орындау журналында (Журнал выполнения) екі жол шығады: **кестенің сілтемесі** және **мұғалім кілті (TOKEN)**.
4. **Начать развертывание → Новое развертывание** → түрі: **Веб-приложение**.
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все** (Все пользователи) — әйтпесе оқушылардың файлы жауап жібере алмайды.
5. **Развернуть** басып, `/exec` деп аяқталатын сілтемені көшіріңіз.
6. Сілтеме мен кілтті файлдарға енгізу керек:
   - екі файлда да `var SEND_URL = "";` жолына сілтемені қойыңыз;
   - мұғалім файлында `var TOKEN = "";` жолына кілтті қойыңыз;
   - немесе файлдарды қайта құрастырыңыз:
     `python3 -I src/build.py <шаблон-ученика.html> <шаблон-учителя.html> <шығыс-папка> --url=<сілтеме> --token=<кілт>`.

Кілтті тек мұғалім файлына қойыңыз: онсыз сынып жауаптарын ешкім оқи алмайды.
Оқушы файлында кілт жоқ, ол тек жауап жібереді және өзінің хат алмасуын ғана оқиды.
