1. if … else1. if … else

Шарт ақиқат болса — if блогы, жалған болса — else блогы орындалады. Блок шегініспен (4 бос орын) жазылады, шарттан кейін қос нүкте : қойылады. Салыстыру: ==, !=, >, <, >=, <= (= — меншіктеу, салыстыру емес).

Если условие истинно — выполняется блок if, если ложно — блок else. Блок пишется с отступом (4 пробела), после условия ставится двоеточие :. Сравнения: ==, !=, >, <, >=, <= (= — присваивание, а не сравнение).

ПрограммаПрограмма
t = 38
if t > 37:
    print("hot")
else:
    print("ok")
print("done")
НәтижеВывод
hot
done

else міндетті емес: шарт жалған болса, if блогы жай ғана өткізіледі.

else не обязателен: если условие ложно, блок if просто пропускается.

2. Кірістірілген if2. Вложенный if

if ішіне тағы бір if жазуға болады. Ішкі шарт сыртқы шарт ақиқат болғанда ғана тексеріледі. Шегініс қай else қай if-ке жататынын көрсетеді.

Внутри if можно написать ещё один if. Внутреннее условие проверяется, только если внешнее истинно. Отступ показывает, к какому if относится else.

ПрограммаПрограмма
age = 15
ticket = True
if ticket:
    if age >= 16:
        print("film 16+")
    else:
        print("cartoon")
else:
    print("buy a ticket")
НәтижеВывод
cartoon
