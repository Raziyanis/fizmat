1. Айнымалы және деректер типтері1. Переменная и типы данных

Айнымалы — мәнге берілген ат: x = 5. Әр мәннің типі бар, оны type() көрсетеді.

Переменная — имя для значения: x = 5. У каждого значения есть тип, его показывает type().

ТипМысалПримерМағынасыСмысл
int7, -3бүтін санцелое число
float2.5, -0.1бөлшек сандробное число
str"сәлем", "7"мәтін (жол)текст (строка)
boolTrue, Falseлогикалық мәнлогическое значение
ПрограммаПрограмма
a = 7
b = 2.5
c = "7"
print(type(a), type(b), type(c))
print(c * 3)
print(int(c) + a)
НәтижеВывод
<class 'int'> <class 'float'> <class 'str'>
777
14

"7" * 3 жолды үш рет қайталайды, ал int("7") жолды санға айналдырады.

"7" * 3 повторяет строку три раза, а int("7") превращает строку в число.

2. Енгізу және шығару2. Ввод и вывод

input() әрқашан жол қайтарады, сондықтан санды int() немесе float() арқылы түрлендіреміз. Бір жолдағы бірнеше санды map бөледі: a, b = map(int, input().split()). Тізім керек болса — list(map(int, input().split())).

input() всегда возвращает строку, поэтому число преобразуем через int() или float(). Несколько чисел из одной строки разбирает map: a, b = map(int, input().split()). Если нужен список — list(map(int, input().split())).

ПрограммаПрограмма
a, b = map(int, input().split())
nums = list(map(int, input().split()))
print(a - b)
print(nums, len(nums))
КірісВвод
9 4
3 8 1 6
НәтижеВывод
5
[3, 8, 1, 6] 4

3. f-жол3. f-строка

f"..." жолының ішінде {} жақшасына айнымалы немесе өрнек жазылады. {x:.2f} — үтірден кейін 2 таңба.

Внутри строки f"..." в скобках {} пишут переменную или выражение. {x:.2f} — 2 знака после точки.

ПрограммаПрограмма
city = "Almaty"
t = 21.456
print(f"{city}: {t:.2f} C")
print(f"{3} + {4} = {3 + 4}")
НәтижеВывод
Almaty: 21.46 C
3 + 4 = 7
