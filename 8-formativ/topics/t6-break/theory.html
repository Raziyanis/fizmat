Қадам саны белгісіз болса, while True: және ішінде if …: break жиі жазылады.

Когда число шагов неизвестно, часто пишут while True: и внутри if …: break.

ПрограммаПрограмма
total = 0
while True:
    w = int(input())
    if w < 0:
        break
    total += w
print(total)

4. for … else, while … else4. for … else, while … else

else циклмен бір деңгейде (if-пен емес!) жазылады. Ол цикл break-сіз соңына дейін жеткенде ғана орындалады — «табылмады» жағдайына ыңғайлы.

else пишется на одном уровне с циклом (не с if!). Он выполняется, только если цикл дошёл до конца без break — удобно для случая «не найдено».

ПрограммаПрограмма
for w in ["cat", "dog", "owl"]:
    if len(w) > 3:
        print("long:", w)
        break
else:
    print("no long words")
НәтижеВывод
no long words
