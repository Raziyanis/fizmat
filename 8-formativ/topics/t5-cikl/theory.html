2. for және range2. for и range

range(a, b, s) — a-дан бастап, s қадаммен, b-ға жетпей тоқтайтын сандар. range(n) = 0, 1, …, n−1. Қадам саны алдын ала белгілі болса — for.

range(a, b, s) — числа от a с шагом s, не доходя до b. range(n) = 0, 1, …, n−1. Если число шагов известно заранее — for.

ПрограммаПрограмма
for i in range(10, 0, -3):
    print(i, end=" ")
print()
print(list(range(4)))
НәтижеВывод
10 7 4 1 
[0, 1, 2, 3]

3. while3. while

while шарт: — шарт ақиқат болғанша қайталайды. Қадам саны белгісіз болса ыңғайлы. Цикл ішінде шартқа әсер ететін айнымалы өзгеруі керек, әйтпесе цикл шексіз болады.

while условие: — повторяет, пока условие истинно. Удобен, когда число шагов неизвестно. Внутри цикла переменная из условия должна меняться, иначе цикл станет бесконечным.

ПрограммаПрограмма
money = 1000
years = 0
while money < 1500:
    money = money + money // 10
    years += 1
print(years, money)
НәтижеВывод
5 1610

4. Жинақтаушы және санауыш4. Накопитель и счётчик

Қосынды үшін s = 0, көбейтінді үшін p = 1, санау үшін c = 0 деп циклге дейін бастаймыз, ал цикл ішінде жаңартамыз.

Для суммы до цикла пишем s = 0, для произведения p = 1, для подсчёта c = 0, а внутри цикла обновляем.

ПрограммаПрограмма
s = 0
c = 0
for x in [4, 9, 12, 7, 30]:
    if x % 3 == 0:
        s += x
        c += 1
print(s, c)
НәтижеВывод
51 3
