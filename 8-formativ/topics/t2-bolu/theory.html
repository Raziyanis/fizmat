1. Бүтін бөлу // және қалдық %1. Деление нацело // и остаток %

a // b — бөліндінің бүтін бөлігі, a % b — бөлу қалдығы. / әрқашан бөлшек (float) береді.

a // b — целая часть частного, a % b — остаток от деления. / всегда даёт дробное (float).

ПрограммаПрограмма
print(23 // 5, 23 % 5, 23 / 5)
sec = 200
print(sec // 60, sec % 60)
НәтижеВывод
4 3 4.6
3 20

Санның цифрлары: n % 10 — соңғы цифр, n // 10 — соңғы цифрды алып тастау. Сан жұп па — n % 2 == 0, k-ға бөліне ме — n % k == 0.

Цифры числа: n % 10 — последняя цифра, n // 10 — отбросить последнюю цифру. Чётность — n % 2 == 0, делимость на k — n % k == 0.

ПрограммаПрограмма
n = 5084
print(n % 10, n // 10 % 10, n // 1000)
НәтижеВывод
4 8 5

2. Құрама шарттар: and, or, not2. Составные условия: and, or, not

МағынасыСмыслМысалПример
andекеуі де ақиқатоба истинныx > 0 and x < 10
orкем дегенде біреуі ақиқатхотя бы одно истинноd == 6 or d == 7
notкерісіншенаоборотnot x % 3 == 0
ПрограммаПрограмма
x = 14
print(x > 10 and x % 2 == 0)
print(x < 0 or x % 7 == 0)
print(not x > 10)

True
False

Аралықты Python-да қысқа жазуға болады: 0 < x < 10 — бұл 0 < x and x < 10 дегенмен бірдей.

Диапазон в Python можно записать коротко: 0 < x < 10 — то же, что 0 < x and x < 10.
