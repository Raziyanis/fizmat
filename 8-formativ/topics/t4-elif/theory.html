1. Көп таңдау: if … elif … else1. Множественный выбор: if … elif … else

Нұсқалар екіден көп болса, elif («әйтпесе, егер») қолданамыз. Шарттар жоғарыдан төмен тексеріледі; бірінші ақиқат шарттың блогы орындалады, қалғандары өткізіледі. Ешбірі ақиқат болмаса — else.

Если вариантов больше двух, используем elif («иначе, если»). Условия проверяются сверху вниз; выполняется блок первого истинного условия, остальные пропускаются. Если ни одно не истинно — else.

ПрограммаПрограмма
speed = 75
if speed > 90:
    print("fine")
elif speed > 60:
    print("warning")
else:
    print("ok")
НәтижеВывод
warning

2. Шарттардың реті маңызды2. Порядок условий важен

Кең шартты бірінші жазсақ, тар шарт ешқашан тексерілмейді. Сондықтан шекараларды бір бағытта: үлкеннен кішіге (немесе керісінше) жазыңыз.

Если первым поставить широкое условие, узкое никогда не проверится. Поэтому записывайте границы в одном направлении: от большего к меньшему (или наоборот).

ПрограммаПрограмма
speed = 95
if speed > 60:
    print("warning")
elif speed > 90:
    print("fine")
НәтижеВывод
warning

95 > 90 болса да, «fine» шықпады: бірінші шарт ақиқат болды, қалғаны тексерілмеді.

Хотя 95 > 90, «fine» не вывелось: первое условие оказалось истинным, остальные не проверялись.
