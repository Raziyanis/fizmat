# Формативтік бағалау, 8-сынып / Формативное оценивание, 8 класс

7 тақырып, әрқайсысы — жеке офлайн HTML-файл (интернетсіз ашылады, Python браузерде — Skulpt).
7 тем, каждая — отдельный офлайн HTML-файл (открывается без интернета, Python в браузере — Skulpt).

| № | Мақсат / Цель | Файл |
|---|---|---|
| 1 | 8.1.1.2 Айнымалылар, типтер, енгізу/шығару, f-жол, map | `formativ-1-ainymaly-tipter.html` |
| 2 | 8.1.8.2 `//`, `%`, құрама шарттар | `formativ-2-bolu-kurama-shart.html` |
| 3 | 8.1.2.4 if, кірістірілген if | `formativ-3-shart-operatory.html` |
| 4 | 8.1.4.1 elif | `formativ-4-elif.html` |
| 5 | 8.1.4.2 / 8.1.4.4 сызықтық, тармақталған, циклдік алгоритм; while, for | `formativ-5-algoritm-cikl.html` |
| 6 | 8.1.4.5 continue, break, else | `formativ-6-break-continue-else.html` |
| 7 | 8.1.4.6 кірістірілген циклдар | `formativ-7-ishki-cikldar.html` |

**Құрылымы / Структура:** қысқа теория (таймер жүрмейді) → 10 тапсырма, 40 минут:
1–5 — тест (4 нұсқа, 1 балл), 6–10 — программа (8 тест, барлығы өтсе 1 балл). Барлығы 10 балл.
Әр оқушыда сандары басқа нұсқа. Теорияға кез келген уақытта «📖 Теория» батырмасы арқылы оралуға болады.
ҚАЗ/РУС ауыстырғыш, толық экран режимі (2 ескерту, 3-інде жұмыс аяқталады).

**Бір рет кіру / Однократный вход:** оқушы өз атын бір жұмысқа `LOCK_HOURS` (24) сағатта бір рет қана таңдай алады — басқа браузерден де, басқа компьютерден де (скрипттің «Кірулер» парағы). Әзілмен басқаның атын таңдаса — мұғалім «Кірулер» парағынан сол жолды өшіреді. Сол браузерде кездейсоқ жабылған жұмыс жауаптарымен бірге жалғасады (бұзушылық ретінде саналады).
Ученик может выбрать себя в одной работе только раз в 24 ч из любого браузера и компьютера; учитель снимает блокировку, удалив строку на листе «Кірулер».

**Нәтижелер поштаға / Результаты на почту:** барлық 7 файлға **бір** Apps Script жеткілікті
(`engine/server/Code.gs`, APP префиксі `fizmat-formativ-`). Кестеде «Тақырып» бағаны бар.
Сілтемені (…/exec) және сынып тізімін `engine/config.js` ішіне жазыңыз да, қайта жинаңыз.

## Құрастыру / Сборка

```
python3 tools/build-theory.py      # теория: мысалдардың нәтижесі нағыз Python-мен алынады
node tools/build.js                # → standalone/*.html
node tools/build.js my-config.js out/   # басқа баптаулармен (сынып тізімі, сілтеме)
python3 tools/check.py 500         # кілттерді нағыз Python-мен тексеру
```

- `engine/` — ортақ қозғалтқыш: `index.html` (үлгі), `app.js`, `common.js`, `style.css`, `config.js`, `server/Code.gs`.
- `topics/<id>/topic.js` — тақырыптың тапсырмалар генераторы, `theory.html` — `build-theory.py` жасайды.
- Оқушылардың аты-жөні бар файлдар репозиторийге салынбайды.
