# 9.2.5.2 — Множество: set (методы, применяемые к множествам)

Интерактивный веб-ресурс к уроку информатики, 9 класс, 40 минут.
Откройте `index.html` в браузере (нужен интернет: шрифты и интерпретатор Python Skulpt загружаются с CDN).

## Что внутри

| Этап урока | Что есть на странице |
|---|---|
| I. Организационный этап (3′) | Ценности «Адал еңбек», разминка по list / tuple / dict с мгновенной проверкой |
| II. Проблемная ситуация (7′) | Задача о волонтёрах: решение списками и через `set`, живой замер скорости |
| III. Новый материал (10′) | Термины, запускаемые примеры (создание, add/remove/discard, индекс, frozenset), интерактивные круги Эйлера, таблица методов, сравнение коллекций, карточка-памятка для учащихся с ООП |
| IV. Практика (15′) | Задания уровней A, B, C: редактор кода, запуск, пошаговые подсказки, автопроверка |
| V. Рефлексия (5′) | Тренажёр «найди 5 ошибок», «Три точки опоры», лист самооценивания |

Дополнительно: таймер этапа, **режим учителя** (показывает эталонные решения), сохранение ответов в браузере ученика.
Код выполняется прямо в браузере (Skulpt, Python 3); вывод `set` может отличаться по порядку от CPython.
