Вопрос классу: какая главная проблема списков (list), если нужно хранить строго уникальные элементы без повторов?

Ответ

Список допускает повторы. Чтобы их не было, каждый новый элемент приходится проверять вручную через if x not in список, а это долго и громоздко.

Разминка: list, tuple, dict
