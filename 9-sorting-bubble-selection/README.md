# Открытый урок: сортировка методом пузырька и методом выбора (9 класс, Python)

Интерактив для урока на 40 минут, построенного по циклу проблемного обучения:
проблемная ситуация → постановка проблемы → гипотеза → проверка → решение и вывод → применение → рефлексия.

## Файлы
- `index.html` — готовый файл для урока. Открывается двойным щелчком в браузере и работает без интернета.
- `lesson.html` — исходник (без обёртки `<html>`), из него собирается `index.html`: `python3 build.py`.

## Как пользоваться
1. На компьютерах учеников открыть `index.html` (этап 1).
2. На компьютере учителя нажать «Режим учителя»: появятся заметки к каждому этапу (хронометраж по минутам,
   ключевые вопросы, ожидаемые ответы, критерии листа наблюдения) и вкладка «Паспорт урока».
3. Таймер в шапке отсчитывает время этапа и общее время урока.
4. В «Паспорте урока» — соответствие 13 критериям листа наблюдения, таблица достижения целей
   (проценты считаются автоматически) и поля самоанализа с кнопкой «Скопировать отчёт».
5. Перед следующим классом: «Паспорт урока» → «Очистить ответы учеников».

Ответы сохраняются только в браузере этого компьютера.
