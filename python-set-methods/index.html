📘 Что такое множество

Множество (set) - коллекция, в которой каждый элемент встречается только один раз.

🎯
Только уникальныеПовторы удаляются автоматически: set([1, 2, 2]) → {1, 2}
🔀
Нет порядка и индексовНельзя написать s[0] - у элементов нет номеров.
🧊
Неизменяемые элементыЧисла, строки, кортежи - можно. Список внутри множества - нельзя.

Как создать множество

s = {3, 1, 2}          # в фигурных скобках
s = set([1, 2, 2])    # из списка → {1, 2}
s = set('мама')       # из строки → {'м', 'а'}
s = set()             # пустое множество
d = {}                # ⚠ это НЕ множество, а пустой словарь (dict)!

        📚 Шпаргалка по множествам
        
      
          
    • Создание: {1, 2, 3} или set([1, 2, 2, 3]) - set() принимает один набор элементов; повторы исчезают. Пустое множество - только set().
      • 
          
    • Проверка: x in s. Перебор: for x in s:
      • 
          
    • Добавление и удаление: s.add(x), s.remove(x) (ошибка, если элемента нет), s.discard(x); размер - len(s).
      • 
          
    • Почему нет индексов: множество - это «мешок» уникальных элементов без номеров. Важно, есть ли элемент, а не что лежит под номером 0, поэтому s[0] вызывает TypeError. Порядок элементов не гарантируется и может меняться от запуска к запуску.
