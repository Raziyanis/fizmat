# Открытый урок: множества (set) в Python

`index.html` - интерактивная страница урока из трёх вкладок. Открывается двойным щелчком в браузере (Chrome, Edge); F11 - на весь экран.

## Вкладка 1. Тема урока

Определение темы через методы списка.

1. **Вспомним методы списка** - карточки `append`, `extend`, `remove`, `pop`, `clear`, `copy`, `len`. Нажатие переворачивает карточку: описание и пример.
2. **Загадка** - кнопка «Дальше» по шагам:
   - элементы списка `[3, 1, 3, 2, 1]` перекладываются в неизвестную коллекцию `x = ▒▒▒(lst)`, повторы исчезают;
   - `x[0]` даёт ошибку - индексов нет;
   - `x.append(5)` даёт ошибку - метода нет;
   - `x.add(5)` работает, повторное `add(5)` ничего не добавляет;
   - вопрос классу, затем «🎉 Открыть тему»: название коллекции проявляется (`set`), крупно выводится тема и цель урока, таблица «метод списка → метод множества».

## Вкладка 2. Новая тема

- что такое множество (три свойства), как создать, почему `{}` - не множество;
- таблица «список и множество»;
- **живая демонстрация** - анимация каждого метода на `s = {1, 4, 6}` с выводом, как в Python;
- **редактор кода** - можно написать и запустить любой код на Python (настоящий Python в браузере, Pyodide). Есть готовые примеры. Ctrl+Enter - запуск. **Нужен интернет**: при первом запуске загружается около 10 МБ (5-20 секунд).
