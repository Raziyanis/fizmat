# Сопоставление: методы множества (set) в Python

Файл `index.html` — интерактивное задание на сопоставление «метод ↔ описание» (8 пар):

| Группа | Методы |
|---|---|
| Добавление | `s.add(x)`, `s.update(t)` |
| Удаление | `s.remove(x)`, `s.discard(x)`, `s.pop()`, `s.clear()` |
| Прочие | `s.copy()`, `len(s)` |

Ученик нажимает на метод, затем на описание; пары помечаются номером и цветом. Кнопка **«Проверить»** становится активной, когда соединены все 8 пар: верные пары подсвечиваются зелёным, неверные красным, ниже выводятся правильные ответы и балл. При каждом открытии порядок карточек перемешивается. Страница работает без интернета, на компьютере и на телефоне.

## Как выдать ученикам

Страница — один HTML-файл без внешних зависимостей, её можно разместить где угодно:

- **GitHub Pages:** Settings → Pages → Branch: `main`, папка `/ (root)`; ссылка будет вида `https://<user>.github.io/fizmat/python-set-methods/`;
- или загрузить `index.html` на Google Диск / Google Sites;
- в Classroom: **Задание → Прикрепить → Ссылка**.

Баллы никуда не отправляются: попросите учеников ввести фамилию и имя и прислать скриншот результата в Classroom.

Чтобы изменить пары, отредактируйте массив `PAIRS` в начале скрипта.
