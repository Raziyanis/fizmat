# Открытый урок: методы множества (set) в Python

`index.html` — интерактивная страница для урока: разбиение класса на пары, задание на сопоставление «метод ↔ описание» (8 пар) с таймером, разбор ошибок и живая демонстрация методов.

| Группа | Методы |
|---|---|
| Добавление | `s.add(x)`, `s.update(t)` |
| Удаление | `s.remove(x)`, `s.discard(x)`, `s.pop()`, `s.clear()` |
| Прочие | `s.copy()`, `len(s)` |

## Ход урока

1. **Пары.** Кнопка «🎲 Разбить на пары» случайно делит класс на пары (при нечётном числе учеников одна группа — тройка) и показывает их на доске с анимацией. Повторное нажатие перемешивает заново. Список учеников — массив `STUDENTS` в скрипте.
2. **Инструкция.** Крупная карточка с правилами; кнопка «▶ Начать · 3:00» открывает задание и запускает таймер.
3. **Задание.** Пара выбирает своё название в поле «Пара» (подсказки появляются после разбиения на этом же устройстве) и соединяет методы с описаниями. На последних 30 секундах таймер мигает красным, кнопка «+1 мин» добавляет минуту. Когда время выходит, ответы проверяются автоматически; несоединённые пары считаются ошибкой.
4. **Результат.** На весь экран крупно выводится счёт (например, «6 / 8»), название пары, оценка и затраченное время.
5. **Разбор ошибок.** У каждой ошибки: «💡 Почему?» — какой метод на самом деле подходит к выбранному описанию, объяснение и подсказка, как не путать похожие методы (например, `remove` и `discard`); «▶ Показать» — анимация метода.
6. **Живая демонстрация.** Для каждого метода — анимация на множестве `s = {1, 4, 6}` и вывод, как в интерпретаторе Python (вывод сверен с настоящим Python).

Звук можно выключить кнопкой 🔊. Время задания — `DEFAULT_LIMIT` в скрипте (в секундах).

## Как открыть

Это один HTML-файл. Работает без интернета (без интернета вместо фирменных шрифтов используются системные).

- На уроке: открыть файл в браузере на компьютере учителя и вывести на доску; ученикам — открыть ту же ссылку на своих устройствах.
- Ссылка для учеников: GitHub Pages (Settings → Pages → Branch: `main`, `/ (root)`, адрес вида `https://<user>.github.io/fizmat/python-set-methods/`) или Google Sites; в Classroom — **Задание → Прикрепить → Ссылка**.

Баллы никуда не отправляются: результат каждой пары виден на её экране (можно прислать скриншот).
