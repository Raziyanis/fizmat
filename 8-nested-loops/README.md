# Урок «Организация вложенных циклов» · 8 класс

`index.html` — интерактивный урок одним файлом. Python (Pyodide) встроен в страницу: программы учеников запускаются и проверяются прямо в браузере, без установки и без интернета. Устроен урок так же, как урок «Одномерный массив. Список»: тот же движок, 12 этапов, вход ученика и отправка ответов учителю.

## Этапы

1. Повторим — циклы for и while (6 вопросов).
2. Разгадай тему — программы робота открывают буквы слов «ВЛОЖЕННЫЕ ЦИКЛЫ».
3. Тема и цель — ожидания ученика, цели, ожидаемые результаты, дескрипторы.
4. Вспомним — `end`, `print()`, `range`.
5. «Вложенный цикл»: цикл в цикле, таблица (`end` и `print()`), треугольники (`range(i)`) — карточки с примерами и редактором кода.
6. «Типовые задачи»: перебор пар, ветвление внутри, счётчик и `break`, шпаргалка и ошибки.
7. Что подходит? — 12 ситуаций: какая конструкция подходит.
8. Практика — разминка и уровни A, B, C (13 заданий с автопроверкой на нескольких наборах данных).
9. Практическая работа — 3 проекта (шахматная доска, ёлочка, покупка без сдачи) и 7 олимпиадных задач с вердиктом (прямоугольник, квадрат из чисел, треугольник, пары с суммой, число делителей, простые числа до n, треугольник из чисел).
10. Тест — пропуски в коде.
11. Итоги урока — самооценка и дескрипторы.
12. Домашнее задание — по одному заданию на уровни A, B, C.

## Данные учащихся

В файле нет списка учащихся (`window.ROSTER = {}`). При входе ученик сам вписывает класс, фамилию и имя, и войти может любой. Если нужно пускать только по списку класса, учитель заполняет `window.ROSTER` в своей копии файла и не публикует её.

Ответы уходят в скрипт учителя по адресу `window.LESSON_URL` — тот же, что в уроке «Одномерный массив». Прогресс хранится под ключами этого урока и не смешивается с другими уроками.

## Что проверить учителю

- Коды целей обучения по учебной программе в файл не вписаны: цели сформулированы текстом (этап 3).
- PIN учителя для разблокировки заданий тот же, что в уроке о списках.
- Есть только русская версия.
