# Двумерные массивы (матрицы) в Python — страница учителя (сделана в Gemini), доработка

`dvumernye-massivy.html` — один файл, интернет не нужен.

Что изменено по сравнению с исходным файлом:
- Python-интерпретатор Skulpt (MIT, та же сборка, что в `../python-kod-formativ/vendor/`) встроен в файл вместо загрузки с cdn.jsdelivr.net.
- Исправлен ввод: `input()` теперь читает данные построчно, как настоящий Python. Раньше каждый `input()` получал одно
  число, и правильные решения с `map(int, input().split())` падали с ошибкой.
- Тесты одной задачи выполняются по очереди; бесконечный цикл останавливается через 2 секунды; вывод программы экранируется.
- Задача 1: в примере и тесте был неверный ответ (5) — для матрицы 1 2 3 / 4 9 6 / 7 8 5 максимум на главной диагонали 9.

Проверено: эталонные решения всех 9 задач проходят тесты на настоящем Python 3 и в файле (Skulpt).
