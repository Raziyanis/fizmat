# Тест 8.2.1.1 — перевод чисел между системами счисления

Цель обучения: перевод натурального числа из десятичной системы счисления в двоичную, восьмеричную, шестнадцатеричную и обратно (8 класс).

Файл `test.gs` — скрипт Google Apps Script. Он сам создаёт в вашем Google Диске:

- **тест Google Forms** (20 вопросов с выбором ответа, 1 балл за вопрос, автоматическая проверка, после ответа ученик видит разбор ошибок);
- **Google Таблицу** с результатами учащихся.

## Как создать тест (≈3 минуты)

1. Откройте <https://script.google.com> под тем же аккаунтом, что и Google Classroom → **Новый проект**.
2. Удалите пример кода, вставьте всё содержимое `test.gs`, сохраните (Ctrl+S).
3. Вверху выберите функцию `createTest` → **Выполнить** → разрешите доступ к Формам и Таблицам.
4. Откройте **Журнал выполнения** — там будут три ссылки: для учеников, для редактирования, таблица результатов.

## Как раздать ученикам в Classroom

1. Classroom → **Задание** → **Прикрепить → Диск** → выберите форму «8.2.1.1 Системы счисления: перевод чисел».
2. Включите **«Импорт оценок»** (появляется, когда прикреплён тест Google Forms) — баллы попадут в журнал Classroom автоматически. Баллы задания: 20.
3. **Создать задание**.

## Где смотреть результаты

- В форме → вкладка **Ответы**: сводка, результаты по каждому ученику, самые трудные вопросы;
- в Google Таблице — все ответы и баллы;
- в Classroom — оценки после «Импорта оценок».

## Настройки теста

- Вход через Google-аккаунт обязателен, пройти тест можно один раз.
- Порядок вопросов и вариантов ответа перемешан.
- Изменить вопросы можно в массиве `QUESTIONS` в `test.gs` (первый вариант ответа — правильный) и перезапустить `createTest`.
