# Тест 8.2.1.1: перевод чисел между системами счисления (индивидуальные варианты)

Цель обучения: перевод натурального числа из десятичной системы счисления в двоичную, восьмеричную, шестнадцатеричную и обратно (8 класс).

Скрипт `test.gs` (Google Apps Script) создаёт в вашем Google Диске:

- **30 вариантов теста** в Google Forms. Задания во всех вариантах одинаковые по типу и сложности, но числа разные (20 вопросов, по 1 баллу, проверка автоматическая, после сдачи ученик видит разбор своих ошибок);
- **одну Google Таблицу** с тремя листами:
  - **«Результаты»** — после каждой сдачи сюда записываются время, вариант, фамилия и имя, email и баллы;
  - **«Варианты»** — ссылки на все варианты и какому ученику выдан каждый вариант;
  - **«Ключи»** — правильные ответы ко всем вариантам.

Количество вариантов задаётся в строке `var VARIANTS = 30;`. Если изменить `SEED`, получится другой набор чисел.

## 1. Создать тесты

1. Откройте <https://script.google.com> под аккаунтом, через который вы работаете в Classroom, → **Новый проект**.
2. Вставьте всё содержимое `test.gs` и сохраните (Ctrl+S).
3. Выберите функцию `createTests` → **Выполнить** → разрешите доступ. Создание 30 вариантов занимает 1–3 минуты.
4. Ссылка на таблицу появится в **Журнале выполнения**.

## 2. Раздать ученикам (одна ссылка, у каждого свой вариант)

1. В редакторе скрипта: **Начать развертывание → Новое развертывание → Тип: Веб-приложение**.
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все пользователи в домене вашей школы** (или «Все, у кого есть аккаунт Google»).
2. Скопируйте ссылку веб-приложения (заканчивается на `/exec`).
3. В Classroom: **Задание → Прикрепить → Ссылка** → вставьте эту ссылку → Создать задание.

Когда ученик открывает ссылку, скрипт закрепляет за его аккаунтом свободный вариант (это видно на листе «Варианты»). Если открыть ссылку ещё раз, откроется тот же вариант.

**Важно:** скрипт узнаёт ученика по email, а Google передаёт email только пользователям **из того же домена**, что и аккаунт учителя (например, все на `@school.edu.kz`). Если ученики работают с личных `@gmail.com`, веб-приложение не сможет определить аккаунт. Тогда раздайте ссылки вручную: скопируйте ссылки с листа «Варианты» и отправьте каждому ученику его вариант в личном комментарии Classroom.

## 3. Результаты

- Лист **«Результаты»** в таблице — итоговые баллы всех учеников вместе (обновляется автоматически);
- в каждой форме на вкладке **Ответы** — подробный разбор по вопросам.

Автоматический «Импорт оценок» в журнал Classroom работает, только когда к заданию прикреплена одна форма. При индивидуальных вариантах баллы берите с листа «Результаты».
