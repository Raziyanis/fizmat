    Что такое множество

    Определение

    Множество (set, жиын) — это изменяемый набор уникальных элементов, которые хранятся без определённого порядка, поэтому у них нет индексов.

    Уникальность

    Повторы автоматически удаляются.

    set([1, 2, 2, 3])
# {1, 2, 3}

    Нет порядка и индексов

    Обратиться к элементу по номеру нельзя.

    s[0]  # TypeError

    Изменяемость

    Элементы можно добавлять и удалять.

    s.add(5)
s.discard(2)
