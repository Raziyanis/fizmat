Кортеж: tuple

Список можно менять, а бывают данные, которые меняться не должны: дни недели, дата рождения, координаты точки, цвет. Для них в Python есть кортеж — «список только для чтения».

Основные понятия

Кортеж (tuple)

упорядоченный набор значений, который после создания нельзя изменить: ("Пн", "Вт", "Ср").

Неизменяемость

элементы кортежа нельзя заменить, добавить или удалить. Можно только создать новый кортеж.

Индекс

номер элемента, как в списке: счёт с 0, с конца — отрицательные номера.

Распаковка

раздача элементов кортежа по переменным: d, m, y = (12, 5, 2011).

Упаковка

сборка нескольких значений в кортеж: date = 12, 5, 2011.

Коллекции Python

список (list), кортеж (tuple), множество (set) и словарь (dict). Сегодня — кортеж и его отличия от списка.

tuple — кортеж

Простыми словами: кортеж — как список, напечатанный в книге: читать можно, исправить нельзя.

Где применяется

  • Дни недели: days = ("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс")
  • Дата рождения: birthday = (12, 5, 2011)
  • Точка на плоскости: point = (3, 5)
  • Цвет в формате RGB: white = (255, 255, 255)

Не подходит: если данные будут меняться — добавляться, удаляться, сортироваться, — нужен список.

Как записать: t = (3, 8, 1), t = 3, 8, 1, t = ("яблоко",)

Определение

Кортеж (tuple) — упорядоченная неизменяемая коллекция элементов. Элементы записывают в круглых скобках через запятую. Скобки можно не писать: t = 3, 8, 1 — тоже кортеж.

Синтаксис

имя = (элемент1, элемент2, …)

Пустой кортеж: t = (). Кортеж из одного элемента: t = ("яблоко",) — запятая обязательна.

Примеры

Кнопка «Открыть в редакторе» переносит пример в редактор ниже — там его можно изменить и запустить.

Свойства кортежа

  • Упорядочен: у элементов постоянный порядок, и он не меняется.
  • Неизменяем: после создания элементы нельзя заменить, добавить или удалить.
  • Допускает повторы: одно значение может встречаться несколько раз — (5, 4, 5).

Важно знать

  • Без запятой ("яблоко") — это не кортеж, а просто строка в скобках.
  • Python выводит кортеж в круглых скобках: ('яблоко', 'банан').
  • В кортеже могут быть значения разных типов: ("Айдана", 14, "8А").

Запомни: кортеж — круглые скобки и неизменяемость. Кортеж из одного элемента пишут с запятой: ("яблоко",).

t[i], t[i:j], x in t — доступ к элементам

Простыми словами: читать кортеж можно так же, как список: по номеру, кусочком-срезом и с проверкой «есть ли такой элемент».

Где применяется

  • Год из даты рождения: birthday[2]
  • Последний день недели: days[-1]
  • Рабочие дни: days[:5]
  • Выходной ли «Сб»: "Сб" in days[5:]

Не подходит: присвоить по индексу t[0] = 1 нельзя — кортеж неизменяем.

Как записать: t[1], t[-1], t[2:5], "киви" in t

Определение

Индексы и срезы у кортежа работают так же, как у списка. Срез кортежа t[i:j] — новый кортеж из элементов с индексами от i до j − 1. Оператор x in t даёт True, если x есть в кортеже.

Синтаксис

кортеж[индекс] · кортеж[начало:конец] · x in кортеж

Примеры

Важно знать

  • Первый элемент — t[0], последний — t[-1].
  • Конец среза не входит: t[2:5] — индексы 2, 3, 4.
  • Срез кортежа — тоже кортеж, а сам кортеж не меняется.
Попробуй сам

Запомни: читать кортеж — как список: t[i], t[i:j], in.

Неизменяемость и как обойти её

Простыми словами: в напечатанной книге исправить слово нельзя, но можно переписать текст в тетрадь, исправить там и напечатать заново. С кортежем так же: превращаем в список, меняем, превращаем обратно.

Где применяется

  • Исправить элемент: y = list(t), y[1] = "киви", t = tuple(y)
  • Добавить элемент: t += ("апельсин",)
  • Удалить кортеж целиком: del t

Не подходит: если данные меняются постоянно, сразу храни их в списке.

Как записать: list(t), tuple(y), t += (x,)

Определение

Кортеж неизменяем: t[1] = "киви" вызывает ошибку TypeError, а методов append, remove и других у кортежа нет. Чтобы получить изменённые данные, создают новый кортеж: функция list(t) делает из кортежа список, а tuple(y) — из списка кортеж.

Синтаксис

y = list(t) → изменить y → t = tuple(y)

Примеры

Важно знать

  • Запись t += ("апельсин",) не меняет старый кортеж, а создаёт новый и записывает его в ту же переменную.
  • Удалить один элемент из кортежа нельзя; del t удаляет весь кортеж вместе с именем.
  • Неизменяемость защищает данные от случайной правки.
Попробуй сам

Запомни: кортеж не меняют — создают новый: через list() и tuple() или через +.

Упаковка и распаковка

Простыми словами: упаковка — сложить вещи в коробку, распаковка — разложить их по полкам, каждую на свою. Сколько полок, столько и вещей.

Где применяется

  • Разложить дату: d, m, y = birthday
  • Поменять значения местами: a, b = b, a
  • Первый и все остальные: first, *rest = scores

Не подходит: если элементов много и их число заранее неизвестно, удобнее перебрать кортеж циклом.

Как записать: a, b, c = t, a, *b = t

Определение

Упаковка — создание кортежа из нескольких значений: fruits = ("яблоко", "банан", "вишня"). Распаковка — присваивание элементов кортежа нескольким переменным по порядку: (a, b, c) = fruits; скобки можно не писать.

Синтаксис

перем1, перем2, … = кортеж

Число переменных должно совпадать с числом элементов. Если переменных меньше, одной из них ставят звёздочку: *имя собирает «лишние» элементы в список.

Примеры

Важно знать

  • Переменных больше или меньше, чем элементов, и звёздочки нет — ошибка ValueError.
  • Звёздочку можно поставить у любой переменной, но только у одной: first, *middle, last = t.
  • В переменную со звёздочкой попадает список, даже если он пустой.
Попробуй сам

Запомни: a, b, c = t — по одной переменной на элемент; *rest собирает остальные в список.

Перебор кортежа: for, range(len()), while

Простыми словами: перебрать кортеж — пройти по нему от первого элемента до последнего, как по списку.

Где применяется

  • Вывести расписание по дням: for d in days: print(d)
  • Номер дня и его название: for i in range(len(days))

Не подходит: менять элементы во время перебора нельзя — кортеж неизменяем.

Как записать: for x in t:, for i in range(len(t)):

Определение

Цикл for x in t по очереди берёт каждый элемент кортежа. Цикл for i in range(len(t)) перебирает индексы. Цикл while перебирает индексы вручную: начинают с 0 и увеличивают на 1, пока индекс меньше len(t).

Синтаксис

for x in кортеж:

Примеры

Важно знать

  • Функции len, sum, max, min работают с кортежем так же, как со списком.
  • В цикле while не забудь i = i + 1, иначе цикл не закончится.
Попробуй сам

Запомни: перебор кортежа — как перебор списка: for x in t.

+ и * — соединить и повторить

Простыми словами: + — склеить две ленты в одну, * — напечатать одну ленту несколько раз подряд. Старые ленты при этом не меняются.

Где применяется

  • Неделя из будней и выходных: week = work + weekend
  • Расписание звонков на две смены: bells * 2
  • Добавить один элемент: t = t + (7,)

Не подходит: сложить кортеж и список нельзя: (1, 2) + [3] — ошибка TypeError.

Как записать: t1 + t2, t * 2

Определение

Оператор + создаёт новый кортеж: сначала элементы первого кортежа, потом второго. Оператор * с целым числом n создаёт новый кортеж, в котором исходный повторён n раз.

Синтаксис

кортеж1 + кортеж2 · кортеж * число

Примеры

Важно знать

  • Чтобы добавить один элемент, его тоже оформляют кортежем: t + (7,), а не t + 7.
  • Исходные кортежи не меняются: результат — новый кортеж.
Попробуй сам

Запомни: + соединяет, * повторяет — получается новый кортеж.

count() и index() — методы кортежа

Простыми словами: count отвечает на вопрос «сколько раз встречается?», index — «на каком месте стоит?». Кортеж они не меняют, поэтому у кортежа они есть.

Где применяется

  • Номер дня недели: days.index("Ср") + 1
  • Сколько пятёрок в итоговых оценках: marks.count(5)
  • Лучший результат: max(scores)

Не подходит: index для элемента, которого нет, — ошибка ValueError. Сначала проверь через in.

Как записать: t.count(x), t.index(x), len(t)

Определение

count(x) возвращает, сколько раз значение x встречается в кортеже. index(x) возвращает индекс первого элемента, равного x. Функции len, sum, max, min работают с кортежем так же, как со списком.

Синтаксис

кортеж.count(x) · кортеж.index(x)

Примеры

Важно знать

  • У кортежа нет append, remove, sort и других методов, которые меняют данные: t.append(5) — ошибка AttributeError.
  • count для значения, которого нет, даёт 0, а не ошибку.
Попробуй сам

Запомни: у кортежа два метода: count() — «сколько раз?», index() — «где?».

Олимпиадные задачи

Задачи в стиле олимпиад и сайта Codeforces. У каждой задачи — условие, формат входных и выходных данных и примеры. Нажми «Отправить»: программа пройдёт все тесты, а ты получишь вердикт. Если тест не пройден, увидишь его входные данные, правильный ответ и вывод своей программы.

Как в олимпиадах читают и выводят список. Числа часто записаны в одной строке через пробел:

n = int(input())                     # первая строка: количество чисел
a = list(map(int, input().split()))  # вторая строка: все числа — в список
print(*a)                            # вывести элементы через пробел
x, y = map(int, input().split())     # два числа в строке — сразу в две переменные

input().split() разрезает строку по пробелам, map(int, …) превращает каждую часть в число, list(…) собирает числа в список. print(*a) выводит элементы списка через пробел, без скобок.

Тест: впиши пропущенное

В каждой программе пропущено одно или два слова. Впиши их и нажми «Проверить» или Enter. Во всех заданиях, где не сказано иначе, кортеж такой:

fruits = ("яблоко", "банан", "вишня", "киви", "лимон")
