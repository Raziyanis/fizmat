# Урок 9 класса «Кортеж: tuple. Сөздік: dict»: сервер на Apps Script

`lesson9.gs` — отдельный скрипт **только для 9 класса**. Скрипт 8 класса (`8-odnomernyi-massiv/lesson.gs`) не меняется.

- **Лист «Список»** (Класс | Фамилия Имя): ученик выбирает себя из списка. Если его нет, он нажимает «Меня нет в списке» и вписывает себя; строка добавится с пометкой «новый».
- **Лист «Итоги»** и **лист «Попытки»** — как в 8 классе.
- **Лист «Состояние»** — сохранённый урок каждого ученика. При повторном входе (на любом компьютере) ответы загружаются отсюда.
- **Письмо учителю (с PDF):** сразу — по кнопке «Отправить ответы учителю»; через 10 минут после закрытия окна — если ученик не вернулся в урок.
- **На компьютере ученика** урок хранится 7 минут после закрытия окна, потом стирается.

## Установка

1. Создайте **новую** Google Таблицу → **Расширения → Apps Script**, вставьте `lesson9.gs`, сохраните.
2. Выберите `setup` → **Выполнить** → разрешите доступ (таблицы, почта, **запуск по расписанию**). Скрипт заполнит список 9B, поставит ежеминутную проверку писем и пришлёт тестовое письмо.
3. **Начать развертывание → Новое развертывание → Веб-приложение**: «Запуск от имени» — **Я**, «У кого есть доступ» — **Все**.
4. Ссылку `/exec` вставьте в HTML урока в строку `window.LESSON_URL = "…"` (одно место, в начале файла).

После изменения кода: **Управление развертываниями → ✏ → Новая версия**.
