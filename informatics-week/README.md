# Неделя информатики — экран для LED-панели

Один файл `led-screen.html`. Работает **без интернета**, в любом браузере (Chrome, Edge, Яндекс).

## Как запустить на LED-экране
1. Скопируйте `led-screen.html` на компьютер, подключённый к экрану (флешка).
2. Откройте файл двойным щелчком в браузере.
3. Нажмите **F** — полный экран. Дальше слайды меняются сами.

## Слайды (по кругу)
| Слайд | Что показывает |
|---|---|
| `title` | Заголовок с glitch-эффектом и обратный отсчёт до старта; во время недели — «День N/5» |
| `program` | Все 5 дней + программа на сегодня с метками «СЕЙЧАС» / «ДАЛЕЕ» по реальному времени |
| `task` | Случайная задача на перевод чисел (10↔2, 10↔16), таймер 12 с, затем ответ |
| `rating` | Живой рейтинг классов с анимацией |
| `clock` | Двоичные часы + «время как HEX-цвет» |
| `cipher` | Шифровка дня (Цезарь / двоичный / шестнадцатеричный код), ответ открывается в заданное время |
| `fact` | Исторические факты об информатике |

Внизу — бегущая строка.

## Управление
| Клавиша | Действие |
|---|---|
| **F** | полный экран |
| **→ / ←** | следующий / предыдущий слайд |
| **Пробел** | пауза |
| **A** | панель ведущего: баллы классов (+1/+5/+10), показать ответ шифровки |

Баллы сохраняются в браузере этого компьютера — после перезапуска не пропадут.

## Как настроить
Откройте файл в Блокноте, найдите блок `CONFIG` (в начале `<script>`) и измените:
- `startDate` — дата понедельника недели (сейчас стоит `2026-11-09`);
- `kicker`, `slogan` — название школы и слоган;
- `days` — темы и расписание по дням;
- `classes` — список классов;
- `ciphers` — слово/фраза для шифровки на каждый день (только буквы и пробелы) и время показа ответа;
- `ticker` — тексты бегущей строки;
- `slideSeconds` — длительность слайда.

## Показать только нужные слайды
Добавьте к адресу файла `?scenes=...`, например:
`led-screen.html?scenes=rating,clock` — только рейтинг и часы (удобно на финале).
