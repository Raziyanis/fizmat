# Урок «Кортеж: tuple · 8 класс»: письмо учителю с итогами

`index.html` — страница урока. Ученик **сам вписывает класс, фамилию и имя** на экране входа (например, «8А», «Сейткали Айдана»). Когда он на последнем этапе «Итоги урока» нажимает **«Сохранить итог»**, учителю на почту приходит письмо:

- тема: «Итоги урока «Кортеж: tuple» — Фамилия Имя, 8А»;
- в письме: класс, фамилия и имя (как их вписал ученик), время сдачи, баллы по этапам (повторение, практика A/B/C, практическая работа, тест и др.), самооценка и комментарий ученика.

Если ученик нажмёт «Сохранить итог» ещё раз, придёт новое письмо с обновлёнными данными.

## Настройка (один раз, ~5 минут)

1. Откройте <https://script.google.com> под той почтой, на которую должны приходить письма → **Новый проект**.
2. Вставьте всё содержимое `mail.gs`, сохраните (Ctrl+S).
3. Выберите функцию `testMail` → **Выполнить** → разрешите доступ. На почту придёт пробное письмо.
4. **Начать развертывание → Новое развертывание → Тип: Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все** (иначе ученики без входа в Google не смогут отправить итоги).
5. Скопируйте ссылку веб-приложения (оканчивается на `/exec`).
6. Откройте `index.html` в текстовом редакторе, найдите строку `var MAIL_URL = "";` (в начале блока со скриптами урока) и вставьте ссылку между кавычками:
   ```js
   var MAIL_URL = "https://script.google.com/macros/s/.../exec";
   ```
7. Сохраните файл и раздайте ученикам (сайт, Classroom, файл на компьютерах класса).

Письмо приходит владельцу скрипта. Чтобы отправлять на другой адрес, впишите его в `var TEACHER_EMAIL = "";` в `mail.gs` и сделайте новое развертывание.

## Ограничения

- Нужен интернет в момент нажатия «Сохранить итог». Без интернета итоги сохранятся только на компьютере ученика.
- Google ограничивает число писем в сутки: около 100 для обычного аккаунта Gmail, около 1500 для Google Workspace. Для нескольких классов этого достаточно.
- Если урок опубликован как артефакт Claude, политика безопасности страницы может блокировать отправку на внешние адреса. Надёжнее раздавать сам файл `index.html` или размещать его на сайте.
- Онлайн-версия урока в Apps Script (`google.script.run`) вызывает серверную функцию `sendReport`: добавьте `mail.gs` в тот же проект, где лежит серверный код урока.
