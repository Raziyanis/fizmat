# Повторение: методы списка (Python)

Материал для фронтального повторения методов списка в Mentimeter или Wooclap: ученики отвечают со своих устройств, ответы появляются на экране учителя.

Разобранные методы: `append`, `extend`, `insert`, `remove`, `pop`, `index`, `count`, `sort`, `reverse`, `copy`, `clear`.

## Как устроен урок (12–15 минут)

| Этап | Инструмент | Время | Что даёт |
|---|---|---|---|
| 1. Облако слов: что помним | Mentimeter / Wooclap | 2–3 мин | Видно, какие методы класс не вспомнил вообще |
| 2. Открытый вопрос на ключевую путаницу | Mentimeter / Wooclap | 3–4 мин | Видно формулировки учеников, а не только выбор из вариантов |
| 3. Разбор ловушек | Google Таблица или Forms | 5–7 мин | Снимает ограничение бесплатного тарифа |

Бесплатные тарифы Mentimeter и Wooclap ограничивают число вопросов в одной сессии (у Mentimeter — порядка двух вопросов на презентацию). Лимиты меняются, проверьте условия перед уроком. Поэтому в платформу идут только этапы 1–2, где живая стена ответов действительно нужна; этап 3 с автопроверкой — в Google Forms.

## Этап 1. Облако слов

Тип слайда: **Word Cloud** (Mentimeter) или **Nuage de mots / Word cloud** (Wooclap).

> Какие методы списка вы помните? Пишите по одному в каждом поле, без скобок.

Настройки: разрешить 3–5 ответов от одного участника.

Чего ждать: крупными словами выйдут `append` и `pop`, мелкими или вовсе отсутствующими — `extend`, `insert`, `count`, `copy`, `clear`. Это и есть материал для разбора: проговорите вслух именно те методы, которые в облаке не появились.

## Этап 2. Открытый вопрос

Тип слайда: **Open Ended** (Mentimeter) или **Question ouverte / Open question** (Wooclap). Выберите один вопрос из трёх — тот, где у вашего класса слабее место.

**Вариант А (разница remove и pop):**
> Список `a = [10, 20, 30]`. Чем отличается `a.remove(20)` от `a.pop(1)`? Ответьте одним предложением.

Ожидаемое: `remove` удаляет по значению, `pop` — по индексу и возвращает удалённый элемент.

**Вариант Б (append и extend):**
> `a = [1, 2]`. Что будет в списке после `a.append([3, 4])` и что — после `a.extend([3, 4])`?

Ожидаемое: `[1, 2, [3, 4]]` — длина 3; и `[1, 2, 3, 4]` — длина 4.

**Вариант В (методы, изменяющие список на месте):**
> Почему `print(a.sort())` выводит `None`?

Ожидаемое: `sort` сортирует список на месте и ничего не возвращает; новый отсортированный список даёт функция `sorted(a)`.

## Этап 3. Ловушки (Google Forms или общая таблица)

Вопросы с автопроверкой. В каждом — один правильный ответ.

1. `a = [1, 2, 3]` → `a.pop(0)`. Что вернёт выражение и что останется в `a`?
   - **`1`, список `[2, 3]`** ✔
   - `1`, список `[1, 2, 3]`
   - `3`, список `[1, 2]`
   - Ошибка

2. `a = [1, 2, 2, 3]` → `a.remove(2)`. Что станет с `a`?
   - **`[1, 2, 3]`** ✔
   - `[1, 3]`
   - `[1, 2, 2, 3]`
   - Ошибка

   Комментарий для разбора: `remove` удаляет только первое вхождение.

3. `a = [1, 2, 3]` → `a.insert(1, 9)`. Что станет с `a`?
   - **`[1, 9, 2, 3]`** ✔
   - `[9, 1, 2, 3]`
   - `[1, 2, 9, 3]`
   - `[1, 9, 3]`

4. `a = [5, 7, 5, 5]`. Что вернёт `a.count(5)`?
   - **`3`** ✔
   - `2`
   - `1`
   - `0`

5. `a = ['x', 'y', 'z']`. Что вернёт `a.index('z')`?
   - **`2`** ✔
   - `3`
   - `'z'`
   - Ошибка

6. `a = [1, 2, 3]`; `b = a`; `b.append(4)`. Что выведет `print(a)`?
   - **`[1, 2, 3, 4]`** ✔
   - `[1, 2, 3]`
   - `[4]`
   - Ошибка

   Комментарий: `b = a` не создаёт новый список, оба имени ссылаются на один объект. Независимую копию даёт `b = a.copy()`.

7. `a = [3, 1, 2]`. Что выведет `print(a.sort())`?
   - **`None`** ✔
   - `[1, 2, 3]`
   - `[3, 1, 2]`
   - Ошибка

8. `a = [1, 2, 3]` → `a.clear()`. Что станет с `a`?
   - **`[]`** ✔
   - `None`
   - Переменная `a` удалится
   - `[1, 2, 3]`

9. `a = [1, 2, 3]` → `a.reverse()`. Что станет с `a` и что вернёт сам вызов?
   - **`[3, 2, 1]`, вызов возвращает `None`** ✔
   - `[3, 2, 1]`, вызов возвращает `[3, 2, 1]`
   - `[1, 2, 3]`, вызов возвращает `[3, 2, 1]`
   - Ошибка

10. `a = [1, 2]`. Какой вызов приведёт к ошибке?
    - **`a.remove(5)`** ✔
    - `a.append(5)`
    - `a.insert(10, 5)`
    - `a.count(5)`

    Комментарий: `remove` требует, чтобы значение было в списке; `insert` с индексом за границей просто добавляет в конец, `count` возвращает `0`.

## Визуализация для разбора

Вопросы 6 и 7 — главные источники ошибок, и словами они объясняются плохо. Откройте <https://pythontutor.com>, вставьте код и пройдите по шагам: ученики увидят, что `b = a` рисует вторую стрелку на тот же список, а `sort` меняет его на месте. Без регистрации и бесплатно.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)

c = [3, 1, 2]
d = c.copy()
d.sort()
print(c, d)
```

## Если Mentimeter и Wooclap не подойдут

Этапы 1–2 работают и на бесплатной Google Таблице: лист с колонкой на каждого ученика, вы открываете её на проекторе, ответы появляются по мере набора. Облака слов не будет, зато нет лимитов и видно авторство каждой записи.
