# Повторение: методы списка (Python)

Веб-приложение на Google Apps Script для фронтального повторения методов списка. Две страницы:

- **страница ученика** — каждый отвечает со своего устройства, 13 тестовых заданий, автопроверка, после сдачи ученик сразу видит разбор своих ошибок;
- **страница учителя** — живая таблица: кто сдал, какой балл, кто на каком задании ошибся, и диаграмма «что разбирать в первую очередь» (задания отсортированы от худшего процента к лучшему).

Ответы пишутся в Google Таблицу на лист «Результаты».

Разобранные методы: `append`, `extend`, `insert`, `remove`, `pop`, `index`, `count`, `sort`, `reverse`, `copy`, `clear`, плюс два задания на разницу между `b = a` и `b = a.copy()` и на то, какой вызов даёт ошибку.

## 1. Создать проект

1. Откройте <https://script.google.com> под аккаунтом, через который вы работаете в Classroom → **Новый проект**.
2. Содержимое `code.gs` вставьте в файл `Код.gs` (он уже открыт).
3. Создайте два файла HTML: **+ → HTML**, имя `student` → вставьте содержимое `student.html`; ещё раз **+ → HTML**, имя `teacher` → вставьте содержимое `teacher.html`.

   Имена должны быть ровно `student` и `teacher`, без расширения — редактор подставит `.html` сам.
4. Сохраните (Ctrl+S).
5. Выберите функцию `setup` → **Выполнить** → разрешите доступ.
6. В **Журнале выполнения** появятся ссылка на таблицу результатов и **ключ страницы учителя** — скопируйте ключ, он понадобится на шаге 3.

## 2. Развернуть и раздать ученикам

1. **Начать развертывание → Новое развертывание → Тип: Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все пользователи в домене вашей школы** (или «Все, у кого есть аккаунт Google», если ученики с личных аккаунтов).
2. Скопируйте ссылку веб-приложения (заканчивается на `/exec`).
3. В Classroom: **Задание → Прикрепить → Ссылка** → вставьте ссылку → Создать задание.

Ученик открывает ссылку, вводит фамилию и имя (если он из того же домена, что и вы, email подставится сам и поле будет закрыто для правки), отвечает и нажимает «Сдать работу».

Порядок заданий у каждого ученика свой — он перемешивается при открытии страницы. Варианты ответов не перемешиваются: так после урока удобно разбирать задания по номерам на вашем экране.

## 3. Экран учителя

Откройте в отдельной вкладке:

```
<ссылка веб-приложения>/exec?page=teacher&key=КЛЮЧ
```

где `КЛЮЧ` — значение из журнала выполнения `setup()`. Страница сама обновляется каждые 7 секунд.

Доступ проверяется двумя способами: по ключу в ссылке либо по вашему аккаунту (если он совпадает с аккаунтом, под которым выполнялся `setup`). Ученику страница без ключа не откроется. Ключ не публикуйте в Classroom — он даёт доступ к результатам всего класса.

Если выводите экран на проектор, помните: на нём видны фамилии и баллы всех учеников. Для разбора ошибок достаточно блока «Что разбирать в первую очередь» — прокрутите страницу так, чтобы таблица с фамилиями осталась за кадром.

## 4. Перед следующим уроком

Функция `clearResults` удаляет все ответы, оставляя заголовок таблицы. Выполняйте её, если хотите начать с чистого листа; иначе результаты просто накапливаются, а на экране учителя у каждого ученика остаётся последняя попытка и счётчик попыток.

Повторное прохождение разрешено специально: это повторение, а не контрольная. Ученик нажимает «Пройти ещё раз» и видит свой прогресс.

## 5. Как менять задания

Банк заданий — массив `QUESTIONS` в начале `code.gs`. Каждое задание:

```js
{
  id: 'q14',               // уникальный код, попадёт в заголовок таблицы
  topic: 'pop',            // метод или тема, показывается ученику и в статистике
  code: 'a = [1, 2]\n...', // код задания, выводится моноширинным блоком
  text: 'Что выведет программа?',
  options: ['…', '…', '…', '…'],
  correct: 2,              // индекс правильного варианта, считая с нуля
  note: 'Пояснение…'       // ученик видит после сдачи
}
```

После добавления или удаления заданий выполните `setup()` ещё раз, если таблица результатов пустая: число колонок в заголовке зависит от числа заданий. Если в таблице уже есть ответы, сначала `clearResults()`, затем удалите лист «Результаты» вручную и выполните `setup()` — иначе старые строки окажутся короче заголовка.

Следите за тем, чтобы правильный ответ не стоял постоянно на одной позиции: сейчас индексы правильных вариантов распределены между 0 и 3.

## 6. Разбор на доске

Задания 8 и 9 (`b = a` против `b = a.copy()`) и 10 (`print(a.sort())` даёт `None`) — главные источники ошибок, и словами они объясняются плохо. Откройте <https://pythontutor.com>, вставьте код и пройдите по шагам: ученики увидят, что `b = a` рисует вторую стрелку на тот же список, а `sort` меняет его на месте.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)

c = [3, 1, 2]
d = c.copy()
d.sort()
print(c, d)
```

## 7. Ограничения

Веб-приложение не может запретить ученику открыть другую вкладку — браузеры этого не позволяют. Способы удержать класс в тесте («Режим блокировки» Google Forms на управляемых Chromebook, Safe Exam Browser на Windows и macOS) описаны в `../8.2.1.1-number-systems/README.md`, раздел 4. Для повторения это, как правило, и не нужно: ученик, который подсмотрит правильный ответ в интернете, всё равно прочитает пояснение после сдачи.

Автоматический «Импорт оценок» в журнал Classroom работает только с прикреплённой формой Google Forms. Здесь баллы берите с листа «Результаты» или с экрана учителя.
