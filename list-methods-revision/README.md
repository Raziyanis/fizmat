# Повторение: методы списка (Python)

Веб-приложение на Google Apps Script. Две страницы:

- **страница ученика** — выбирает свой класс, находит себя в списке, проходит 13 тестовых заданий, сразу видит разбор своих ошибок;
- **страница учителя** — живая таблица: кто сдал, какой балл, кто на каком задании ошибся, кто ещё не сдал, и блок «что разбирать в первую очередь».

Разобранные методы: `append`, `extend`, `insert`, `remove`, `pop`, `index`, `count`, `sort`, `reverse`, `copy`, `clear`, плюс задания на разницу между `b = a` и `b = a.copy()` и на то, какой вызов даёт ошибку.

## Персональные данные

Репозиторий публичный, поэтому **фамилий учеников в нём нет и быть не должно**. Списки классов хранятся только на листе «Классы» в вашей Google Таблице, то есть в вашем Google-аккаунте. Файл `classes.csv` со списками лежит у вас локально и добавлен в `.gitignore` — в GitHub он не попадёт.

## 1. Создать проект

1. Откройте <https://script.google.com> под рабочим аккаунтом → **Новый проект**.
2. Содержимое `code.gs` вставьте в файл `Код.gs`.
3. Создайте два файла HTML: **+ → HTML**, имя `student` → вставьте `student.html`; ещё раз **+ → HTML**, имя `teacher` → вставьте `teacher.html`.

   Имена должны быть ровно `student` и `teacher`. Расширение `.html` редактор добавит сам — дописывать его не нужно.
4. Сохраните (Ctrl+S) → выберите функцию `setup` → **Выполнить** → разрешите доступ.
5. В **Журнале выполнения** появятся ссылка на таблицу и **ключ учителя** — скопируйте ключ.

## 2. Загрузить списки классов

1. Откройте созданную таблицу, перейдите на лист **«Классы»**.
2. Откройте `classes.csv` (он у вас локально, рядом с этими файлами) и скопируйте всё, кроме строки заголовка.
3. Вставьте в таблицу начиная с ячейки **A2**. Должны получиться две колонки: класс и фамилия с именем.

Сейчас в файле 64 ученика: 8A — 12, 8B — 11, 8D — 13, 8E — 14, 8F — 14.

Если лист «Классы» оставить пустым, приложение не сломается: ученик будет вводить фамилию вручную.

## 3. Развернуть и раздать

1. **Начать развертывание → Новое развертывание → Тип: Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все пользователи в домене вашей школы** (или «Все, у кого есть аккаунт Google»).
2. Скопируйте ссылку (заканчивается на `/exec`) и прикрепите к заданию в Classroom.

Порядок заданий у каждого ученика свой — он перемешивается при открытии страницы. Порядок вариантов ответа одинаковый: так после урока удобно разбирать задания по номерам.

## 4. Экран учителя

```
<ссылка веб-приложения>?page=teacher&key=КЛЮЧ
```

Страница обновляется каждые 7 секунд. Сверху кнопки классов — можно смотреть один класс или все сразу. На кнопке класса написано, сколько учеников из списка уже сдали; если отвечал кто-то, кого в списке нет, это показано отдельно как «+N не из списка».

Ключ не публикуйте в Classroom: он открывает результаты всего класса. Если выводите экран на проектор, помните, что на нём видны фамилии и баллы — для разбора достаточно блока «что разбирать в первую очередь».

## 5. Если ученика нет в списке

На экране выбора есть кнопка **«Меня нет в списке»**. Ученик пишет фамилию и имя, проходит тест, и его автоматически дописывают на лист «Классы» — в следующий раз он уже будет в списке. Повторно одна и та же фамилия не добавляется.

## 6. Если пропал интернет

Если в момент сдачи связь оборвалась, ответ не теряется: он сохраняется в памяти браузера на устройстве ученика, и страница сама отправляет его, когда интернет возвращается. Ученик видит предупреждение и просьбу не закрывать вкладку. Как только ответ ушёл, появляется разбор ошибок.

Защита от дублей: у каждой отправки свой номер, поэтому повторная отправка после обрыва не создаёт вторую строку в таблице.

Границы этого механизма, о которых стоит знать:

- ответ лежит **на устройстве ученика**, а не на сервере. Если он закроет вкладку и больше не откроет ссылку — ответ не уйдёт;
- в режиме инкогнито или при запрете хранилища сохранить не удастся. Тогда ученик увидит прямое сообщение: не закрывать страницу и нажать «Сдать работу» ещё раз, когда появится интернет;
- разбор ошибок требует сервера, поэтому оффлайн ученик его не увидит — только после отправки.

## 7. Перед следующим уроком

`clearResults` удаляет ответы, списки классов не трогает. Повторное прохождение разрешено специально: это повторение, а не контрольная; на экране учителя у каждого ученика остаётся последняя попытка и счётчик попыток.

## 8. Если что-то не работает

Выполните в редакторе функцию **`diagnose`** и откройте журнал выполнения. Она проверит и напишет: создана ли таблица, есть ли ключ учителя, найдены ли HTML-файлы `student` и `teacher`, сколько классов и учеников в списках, сколько ответов записано.

Самая частая причина пустой страницы — HTML-файл назван не так. Должно быть ровно `student` и `teacher`.

## 9. Как менять задания

Банк заданий — массив `QUESTIONS` в начале `code.gs`:

```js
{
  id: 'q14',               // уникальный код, попадёт в заголовок таблицы
  topic: 'pop',            // метод или тема, видна ученику и в статистике
  code: 'a = [1, 2]\n...', // код задания
  text: 'Что выведет программа?',
  options: ['…', '…', '…', '…'],
  correct: 2,              // индекс правильного варианта, считая с нуля
  note: 'Пояснение…'       // ученик видит после сдачи
}
```

Правильные ответы не должны стоять на одной и той же позиции — сейчас они распределены между 0 и 3.

Если меняете число заданий, число колонок на листе «Результаты» тоже меняется. Порядок: `clearResults()`, затем удалите лист «Результаты» вручную, затем `setup()`. Лист «Классы» при этом не пострадает.

## 10. Разбор на доске

Задания на `b = a` против `b = a.copy()` и на `print(a.sort())` — главные источники ошибок, словами объясняются плохо. Откройте <https://pythontutor.com> и пройдите по шагам: видно, что `b = a` рисует вторую стрелку на тот же список.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)

c = [3, 1, 2]
d = c.copy()
d.sort()
print(c, d)
```

## 11. Ограничения

Веб-приложение не может запретить ученику открыть другую вкладку. Способы удержать класс в тесте описаны в `../8.2.1.1-number-systems/README.md`, раздел 4. Для повторения это обычно и не нужно.

Автоматический импорт оценок в журнал Classroom работает только с прикреплённой формой Google Forms. Здесь баллы берите с листа «Результаты» или с экрана учителя.
