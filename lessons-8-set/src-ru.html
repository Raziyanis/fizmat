Множество: set

В списке одно и то же значение может встречаться много раз. Часто же важно другое — какие значения вообще есть: какие оценки получил класс, кто записался в кружок, какие города посетила семья. Такой набор без повторов в Python называется множеством.

Основные понятия

Множество (set)

набор неповторяющихся элементов в фигурных скобках: {1, 2, 3}.

Без повторов

каждый элемент хранится один раз; set(список) убирает повторы.

Без порядка

у элементов нет номеров; Python может вывести их не в том порядке, в каком их записали.

Операции

объединение |, пересечение &, разность -, симметрическая разность ^.

Методы

add, remove, discard, update, union, intersection, difference, issubset и другие.

Коллекции Python

список, кортеж, множество и словарь. Множество — единственная из них без порядка и без повторов.

set — множество

Простыми словами: множество — как список участников кружка: каждый записан один раз, и неважно, кто записался первым.

Где применяется

  • Участники кружка: chess = {"Айдана", "Тимур", "Дана"}
  • Различные оценки класса: set([5, 4, 5, 3]) → {3, 4, 5}
  • Выигрышные номера лотереи: win = {7, 25, 40}

Не подходит: если важен порядок элементов или повторы — например, очередь или все оценки за четверть, — нужен список.

Как записать: s = {1, 2, 3}, s = set(коллекция), s = set()

Определение

Множество (set) — изменяемая коллекция неповторяющихся элементов без определённого порядка. Элементы записывают в фигурных скобках через запятую. Функция set() создаёт множество из списка, кортежа или строки, а без аргументов — пустое множество.

Синтаксис

имя = {элемент1, элемент2, …} · имя = set(коллекция)

Пустое множество — только set(): запись {} создаёт пустой словарь.

Примеры

Кнопка «Открыть в редакторе» переносит пример в редактор ниже — там его можно изменить и запустить.

Свойства множества

  • Без порядка: у элементов нет номеров, поэтому s[0] — ошибка. Порядок вывода может отличаться от порядка записи и от запуска к запуску; чтобы вывести элементы по порядку, используют sorted(s).
  • Без повторов: повторяющиеся значения хранятся один раз. True и 1, False и 0 считаются одним значением.
  • Изменяемое: элементы можно добавлять и удалять, но сами элементы изменить нельзя.

Важно знать

  • Элементом множества может быть только неизменяемое значение: число, строка, кортеж. Список элементом быть не может.
  • Элементы могут быть разных типов: {"abc", 34, True}.
  • type(s) для множества — <class 'set'>; len(s) — количество элементов.

in, for, sorted — проверка и перебор

Простыми словами: у множества нельзя спросить «кто третий?», но можно спросить «есть ли Тимур?» и пройти по всем участникам.

Где применяется

  • Записан ли ученик в кружок: "Тимур" in chess
  • Вывести участников по алфавиту: for name in sorted(chess):
  • Наибольший выигрышный номер: max(win)

Не подходит: обращение по номеру s[0] — ошибка: у множества нет индексов.

Как записать: x in s, x not in s, for x in s:, sorted(s)

Определение

Оператор x in s проверяет, есть ли элемент во множестве, x not in s — что его нет. Цикл for x in s перебирает все элементы, но в каком порядке — не гарантируется. sorted(s) возвращает список элементов по возрастанию. Функции len, min, max, sum работают с множеством так же, как со списком.

Синтаксис

элемент in множество · for элемент in sorted(множество):

Примеры

Важно знать

  • Проверка in во множестве работает быстро даже для очень большого набора: Python не перебирает элементы по одному, как в списке.
  • sorted(s) не меняет множество, а создаёт новый список.
Попробуй сам

Добавление и удаление: add, update, remove, discard

Простыми словами: в кружок можно записать нового ученика или вычеркнуть ушедшего. Записать того, кто уже есть, — ничего не изменится.

Где применяется

  • Новый участник: chess.add("Арман")
  • Записать сразу целый список: chess.update(["Ерлан", "Асель"])
  • Вычеркнуть ученика, даже если его нет: chess.discard("Тимур")

Не подходит: remove для элемента, которого нет, — ошибка KeyError. Тогда используют discard.

Как записать: s.add(x), s.update(коллекция), s.remove(x), s.discard(x), s.pop(), s.clear()

Определение

add(x) добавляет один элемент, update(…) — все элементы другой коллекции: множества, списка, кортежа. remove(x) удаляет элемент, а если его нет — ошибка KeyError. discard(x) удаляет элемент и не выдаёт ошибку, если его нет. pop() удаляет и возвращает какой-то элемент — какой именно, заранее неизвестно. clear() очищает множество, del s удаляет его целиком.

Синтаксис

множество.add(элемент) · множество.discard(элемент)

Примеры

Важно знать

  • Добавить элемент, который уже есть, — не ошибка: множество не изменится.
  • Копия множества — s.copy(); запись b = s копию не создаёт: это второе имя того же множества.
  • У множества нет append и insert: места для элемента не существует, его просто добавляют.
Попробуй сам

Запомни: добавить — add; удалить без ошибки — discard; remove требует, чтобы элемент был.

Список → множество: убрать повторы

Простыми словами: из журнала, где оценки повторяются, множество оставляет по одной оценке каждого вида.

Где применяется

  • Различные оценки: set(marks)
  • Сколько разных значений: len(set(marks))
  • Без повторов и по порядку: sorted(set(marks))
  • Есть ли в списке повторы: len(a) != len(set(a))

Не подходит: если нужно знать, сколько раз встретилось каждое значение, нужен словарь-счётчик: множество хранит только факт «есть».

Как записать: set(a), len(set(a)), sorted(set(a)), list(set(a))

Определение

set(a) превращает список, кортеж или строку во множество — повторы при этом исчезают. Обратно множество превращают в список функциями list(s) или sorted(s); во втором случае элементы стоят по возрастанию.

Синтаксис

set(список) · sorted(set(список))

Примеры

Важно знать

  • list(set(a)) убирает повторы, но порядок элементов может измениться. Нужен порядок по возрастанию — sorted(set(a)).
  • set("строка") — множество букв строки.
Попробуй сам

Запомни: убрать повторы — set(a); сколько разных — len(set(a)).

frozenset — неизменяемое множество

Простыми словами: frozenset — «замороженное» множество: его можно читать и сравнивать, но нельзя дополнить или сократить.

Где применяется

  • Постоянный набор, который нельзя испортить: VOWELS = frozenset("aeiou")
  • Набор как ключ словаря: d[frozenset({1, 2})] = "пара"

Не подходит: если элементы нужно добавлять и удалять — нужен обычный set.

Как записать: x = frozenset(коллекция)

Определение

frozenset — неизменяемая версия множества. Как и set, хранит неповторяющиеся элементы без порядка. В отличие от set, элементы нельзя добавлять и удалять: методов add, remove, discard, update у него нет. Все операции, которые не меняют множество, работают: union, intersection, difference, issubset и знаки | & - ^.

Синтаксис

frozenset(коллекция)

Примеры

Важно знать

  • frozenset неизменяем, поэтому может быть ключом словаря или элементом другого множества, а обычный set — нет.
  • Тип: <class 'frozenset'>.

Объединение | и пересечение &

Простыми словами: есть два кружка — шахматы и робототехника. Объединение — все, кто ходит хотя бы в один кружок. Пересечение — те, кто ходит в оба.

Где применяется

  • Все участники двух кружков: chess | robo
  • Кто ходит в оба кружка: chess & robo
  • Общие номера билета и выигрыша: ticket.intersection(win)

Не подходит: знак | между множеством и списком — ошибка; со списком работает только метод union.

Как записать: a | b, a.union(b), a & b, a.intersection(b)

Определение

Объединение a.union(b) или a | b — новое множество из всех элементов обоих множеств; общие элементы входят один раз. Пересечение a.intersection(b) или a & b — новое множество только из общих элементов. Методы принимают сразу несколько коллекций через запятую, и не только множества: a.union(b, c, список). Знаки работают только между множествами: a | b | c.

Синтаксис

a.union(b) = a | b · a.intersection(b) = a & b

Примеры

Важно знать

  • union и intersection не меняют a, а возвращают новое множество.
  • Изменить само a: a.update(b) или a |= b; a.intersection_update(b) или a &= b.

Разность - и симметрическая разность ^

Простыми словами: разность — кто ходит в шахматы, но не ходит в робототехнику. Симметрическая разность — кто ходит ровно в один из двух кружков.

Где применяется

  • Кто из класса не сдал работу: pupils - done
  • Только шахматы: chess - robo
  • Ровно один кружок: chess ^ robo

Не подходит: перепутать порядок: a - b и b - a — разные множества.

Как записать: a - b, a.difference(b), a ^ b, a.symmetric_difference(b)

Определение

Разность a.difference(b) или a - b — элементы a, которых нет в b. Симметрическая разность a.symmetric_difference(b) или a ^ b — элементы, которые есть только в одном из множеств: все, кроме общих.

Синтаксис

a.difference(b) = a - b · a.symmetric_difference(b) = a ^ b

Примеры

Важно знать

  • a ^ b = (a | b) - (a & b): всё, кроме общего.
  • Изменить само a: a.difference_update(b) или a -= b; a.symmetric_difference_update(b) или a ^= b.
Попробуй сам

Запомни: a - b — есть в a, нет в b; a ^ b — всё, кроме общего.

Сравнение множеств: issubset, issuperset, isdisjoint

Простыми словами: «все ли ученики 8А пришли на концерт?», «нет ли у двух команд общих игроков?» — на такие вопросы множества отвечают одним словом: True или False.

Где применяется

  • Все ли сдали работу: pupils.issubset(done)
  • Нет ли общих игроков: team1.isdisjoint(team2)
  • Одинаковые ли наборы: a == b

Не подходит: если нужно узнать, какие элементы общие, — нужно пересечение, а не isdisjoint.

Как записать: a.issubset(b) или a <= b, a.issuperset(b) или a >= b, a.isdisjoint(b)

Определение

a.issubset(b) (a <= b) — True, если все элементы a есть в b: a — подмножество b. a < b — строгое подмножество: к тому же в b есть элементы, которых нет в a. a.issuperset(b) (a >= b) — True, если a содержит все элементы b. a.isdisjoint(b) — True, если общих элементов нет. a == b — True, если элементы одинаковые, в любом порядке.

Синтаксис

a.issubset(b) · a.issuperset(b) · a.isdisjoint(b)

Примеры

Важно знать

  • Эти методы ничего не меняют, они только отвечают True или False.
  • Любое множество — подмножество самого себя: a <= a — True, а a < a — False.
Попробуй сам

Запомни: «всё из a есть в b» — a.issubset(b); «общих нет» — a.isdisjoint(b).

Как выбрать

Задай вопрос: «Важны ли порядок и повторы?» Да — список или кортеж. Нет, важно только «есть или нет» — множество. Нужно находить значение по имени — словарь.

Песочница

Какая операция?

Прочитай ситуацию и выбери, что подходит: коллекция, операция или метод множества. Подсказка: «все вместе» — |, «общие» — &, «есть в первом, нет во втором» — -, «ровно в одном» — ^.

Олимпиадные задачи

Задачи в стиле олимпиад и сайта Codeforces. У каждой задачи — условие, формат входных и выходных данных и примеры. Нажми «Отправить»: программа пройдёт все тесты, а ты получишь вердикт. Если тест не пройден, увидишь его входные данные, правильный ответ и вывод своей программы.

Как в олимпиадах читают и выводят список. Числа часто записаны в одной строке через пробел:

n = int(input())                     # первая строка: количество чисел
a = list(map(int, input().split()))  # вторая строка: все числа — в список
print(*a)                            # вывести элементы через пробел
x, y = map(int, input().split())     # два числа в строке — сразу в две переменные
s = set(input().split())            # слова строки — во множество, без повторов

input().split() разрезает строку по пробелам, map(int, …) превращает каждую часть в число, list(…) собирает числа в список. print(*a) выводит элементы списка через пробел, без скобок.
