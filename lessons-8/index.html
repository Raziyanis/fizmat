8.2.2.1

использовать математические функции (СУММ(); ABS(); КОРЕНЬ(); СТЕПЕНЬ(); СУММЕСЛИ()) в электронных таблицах

Цель урока

научиться выполнять вычисления в электронных таблицах с помощью функций СУММ(), ABS(), КОРЕНЬ(), СТЕПЕНЬ() и СУММЕСЛИ().

Ожидаемые результаты · к концу урока

Все учащиеся

находят сумму диапазона с помощью СУММ() и модуль числа с помощью ABS().

Большинство

применяют КОРЕНЬ() и СТЕПЕНЬ(), правильно записывая аргументы через точку с запятой: =СТЕПЕНЬ(A1;2).

Некоторые

суммируют значения по условию с помощью СУММЕСЛИ() и составляют вложенные формулы, например =КОРЕНЬ(ABS(A1)).
