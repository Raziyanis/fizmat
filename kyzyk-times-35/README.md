# Қызық Times – Special Edition 35 (9 декабря 2026)

Презентация шоу для 9-х классов: `Kyzyk_Times_35.pptx` (71 слайд, 6 раундов).

- Таймеры встроены: на слайде с полосой **клик запускает отсчёт** (цифры для ≤30 с, полоса — для всех), в конце появляется «УАҚЫТ БІТТІ! · ВРЕМЯ ВЫШЛО!». Повторный запуск — вернуться на слайд.
- Раунд 5: на слайде с карточками 1–6 номер — это ссылка на задание; кнопки «Орындау 30 сек» и «◀ Карточкалар».
- Ответы и реплики ведущих — в заметках к слайдам (режим докладчика).

Что нужно доделать вручную:
1. Раунд 2 — вставить 5 изображений в пунктирные рамки (вопрос + ответ), удалить надписи-подсказки.
2. Раунд 3 — вписать утверждённые треки на слайд ответов.
3. Награждение — вписать команды-победители.

Пересборка: `node src/build.js out.pptx && python3 src/timers.py out.pptx` (нужны pptxgenjs и python-pptx).
