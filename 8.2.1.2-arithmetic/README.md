# Урок 8.2.1.2: сложение и вычитание в позиционных системах счисления

- `plan-uroka-8.2.1.2.docx` — краткосрочный план урока (45 минут): формативная работа по 8.2.1.1 (15 минут, файл `../8.2.1.1-web-test/standalone/proverochnaya-8.2.1.1.html`), новая тема, практика, взаимопроверка, рефлексия. Номера слайдов в плане совпадают с презентацией.
- `razdatka-8.2.1.2.docx` — раздаточный лист для печати: вариант 1 и вариант 2 (по 2 страницы: уровень A — задания 1–6, уровень B — задания 7–8, дескрипторы на 10 баллов) и ключ для учителя.
- Презентация (15 слайдов) — опубликована как артефакт Claude, скачивается как .pptx или PDF.

Пересборка документов: `NODE_PATH=<папка с пакетом docx> node tools/build-docs.js`. Все ответы вычисляются в `tools/tasks.js` (для задания 8 перебором проверено, что решение единственное).
