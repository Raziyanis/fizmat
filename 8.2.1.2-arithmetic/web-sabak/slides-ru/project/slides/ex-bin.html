1-й разряд: 1 + 1 = 2 ≥ 2 → пишем 0, 1 на уме

2-й: 1 + 1 + 1 = 3 ≥ 2 → пишем 1, 1 на уме

3-й: 0 + 1 + 1 = 2 → пишем 0, 1 на уме

4-й: 1 + 0 + 1 = 2 → пишем 0, 1 на уме

Единицу на уме записываем слева.

Проверка: 11 + 7 = 18 = 16 + 2 = 10010₂ ✔

Двоичная таблица сложения: 0+0=0, 0+1=1, 1+1=10₂ (читается «один-ноль»), 1+1+1=11₂.
