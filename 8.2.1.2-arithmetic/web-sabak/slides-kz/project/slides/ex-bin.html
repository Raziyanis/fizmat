1-разряд: 1 + 1 = 2 ≥ 2 → 0 жазамыз, 1 ойда

2-разряд: 1 + 1 + 1 = 3 ≥ 2 → 1 жазамыз, 1 ойда

3-разряд: 0 + 1 + 1 = 2 → 0 жазамыз, 1 ойда

4-разряд: 1 + 0 + 1 = 2 → 0 жазамыз, 1 ойда

Ойдағы бірді сол жаққа жазамыз.

Тексеру: 11 + 7 = 18 = 16 + 2 = 10010₂ ✔

Екілік қосу кестесі: 0 + 0 = 0, 0 + 1 = 1, 1 + 1 = 10₂ («бір-нөл» деп оқылады), 1 + 1 + 1 = 11₂.
