# Формативтік жұмыс 9.1.2.5 — Бір өлшемді массив: Python тізімдері (9-сынып)

- `sabak-zhospary-9.1.2.5.docx` — қысқа мерзімді сабақ жоспары (қосарланған сабақ, 80 минут; слайд нөмірлері мұғалімнің 22 слайдтық презентациясы бойынша). Жинау: `NODE_PATH=<docx пакеті> node tools/build-plan.js`.
- `standalone/formativ-9.1.2.5-kz.html` — дайын жұмыс (бір файл, интернетсіз ашылады). 20 тапсырма, 25 минут, мұғалімнің құпиясөзі `config.js` ішінде (2026).
- Тақырыптар (сабақтың презентациясы бойынша): тізім құру, индекс (0 және теріс индекс), қиынды, элементті өзгерту,
  append, insert, remove, pop, len, count, index, sort / sort(reverse=True), бірнеше әдіс қатарынан, for циклімен тізімді қарап шығу.
- Әр оқушының сандары әртүрлі (seed). Нәтиже экранында әр тапсырманың шарты, оқушының жауабы және дұрыс жауап көрсетіледі.
- Кілтті тексеру: `python3 tools/check-tasks.py` (әр кодты нағыз Python-да орындайды). Жинау: `node tools/build-standalone.js`.
- Қозғалтқыш (app.js, index.html, style.css) 8.1.4.2 формативтік жұмысынан алынған.
