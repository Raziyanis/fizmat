# Урок «Одномерный массив. Список · 8 класс»: сервер на Apps Script

`lesson.gs` — скрипт учителя, на который указывает `window.LESSON_URL` в HTML-странице урока.

- **Лист «Список»** (Класс | Фамилия Имя) — список учащихся. Страница загружает его строкой
  `<script src="…/exec?roster=1"></script>`. Войти может только ученик из списка. Сервер ещё раз проверяет его, когда принимает ответы.
- **Лист «Итоги»** — одна строка на ученика, обновляется примерно раз в минуту.
- **Лист «Попытки»** — все ответы ученика (повторы не записываются).
- **Письмо учителю** приходит, когда ученик нажимает «📨 Отправить ответы учителю».

## Установка

1. Создайте Google Таблицу → **Расширения → Apps Script**. Вставьте весь `lesson.gs` и сохраните.
2. При необходимости впишите адрес в `TEACHER_EMAIL` (если оставить пустым, письма придут владельцу скрипта).
3. Выберите функцию **`setup`** → **Выполнить** → разрешите доступ. Скрипт создаст листы, заполнит список и пришлёт тестовое письмо.
   **Без этого шага письма не отправляются.**
4. **Начать развертывание → Новое развертывание → Веб-приложение**: «Запуск от имени» — **Я**, «У кого есть доступ» — **Все**.
5. Скопируйте ссылку `/exec` и вставьте её в HTML в двух местах: `window.LESSON_URL = "…"` и `<script src="…/exec?roster=1">`.

Если поменяли код, сделайте **Управление развертываниями → ✏ → Версия: «Новая версия» → Развернуть**. Ссылка останется прежней, а без новой версии по ссылке продолжит работать старый код.

## Если письмо не пришло

| Что видит ученик | Причина |
|---|---|
| «Скрипт учителя старой версии…» | по ссылке работает старый код без обработки ответов урока; нужна новая версия развертывания |
| «Скрипт учителя закрыт (Google просит войти)» | в доступе стоит не «Все» |
| «…письмо учителю не отправлено — …» | ответы сохранены в таблице; причину Google указывает в сообщении (нет разрешения → запустить `setup`; лимит писем: 100 в сутки у gmail.com) |
| «Ответы отправлены учителю на почту» | письмо отправлено; проверьте папки «Спам» и «Промоакции» |
