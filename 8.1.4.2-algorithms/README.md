# Формативная работа 8.1.4.2 — линейные алгоритмы и алгоритмы с ветвлением

Один файл без сервера: **`standalone/formativ-8.1.4.2.html`** (открыть двойным щелчком). 20 заданий, 20 минут, язык программ — Python.

| № | Тип | Что проверяется |
|---|---|---|
| 1 | сопоставление | блоки блок-схемы (овал, параллелограмм, прямоугольник, ромб) |
| 2–3 | выбор ответа | линейный алгоритм; полное ветвление if … else |
| 4 | сопоставление | операторы Python ==, !=, >=, %, // |
| 5 | ввод числа | трассировка блок-схемы с ветвлением |
| 6–12 | что выведет программа | линейные программы, if … else, неполное ветвление, if … elif … else, and, два ветвления подряд |
| 13–16 | заполните пропуск | знак сравнения, ==, elif, int |
| 17 | порядок строк | собрать линейную программу |
| 18 | выбор ответа | правильная запись условия в Python |
| 19 | ввод числа | сколько раз программа выведет «да» |
| 20 | сопоставление | значение условий: True / False |

- Числа в заданиях у каждого ученика свои (задания генерируются случайно при нажатии «Начать»).
- 1 балл за задание, максимум 20; в сопоставлении балл — только если все пары верны.
- Поведение как в работе 8.2.1.1: полноэкранный режим, выход = завершение, возврат к любому заданию, отчёт, оставшееся время, через 5 минут результат скрывается.
- **Пароль учителя: `2026`** (строка `window.TEACHER_PIN = "2026";` в начале файла).

Проверка ключа: `python3 tools/check-tasks.py 300` — генерирует 300 вариантов и выполняет каждую программу настоящим Python.
Сборка файла: `node tools/build-standalone.js`.
