Частые ошибки

1. Конец range не входит

Числа от 1 до n:

Неверно

range(1, n)

Верно

range(1, n + 1)

2. Накопитель внутри цикла

s = 0 — до цикла, иначе сумма обнуляется:

Неверно

for i in a:
    s = 0
    s = s + i

Верно

s = 0
for i in a:
    s = s + i

3. Лишний отступ у print

Печатаем один раз — после цикла:

Неверно

for i in a:
    s = s + i
    print(s)

Верно

for i in a:
    s = s + i
print(s)

4. Переменная while не меняется

Без i = i + 1 цикл бесконечный:

Неверно

while i <= 5:
    print(i)

Верно

while i <= 5:
    print(i)
    i = i + 1

Покажите ошибку 3 на примере суммы 1..5: с отступом выведется 1, 3, 6, 10, 15, без отступа — только 15.
