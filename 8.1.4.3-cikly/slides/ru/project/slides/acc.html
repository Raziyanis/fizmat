Накопители: сумма, произведение, счётчик

Сумма

s = 0
for i in range(1, 6):
    s = s + i
print(s)

→ 15

Произведение

p = 1
for i in range(1, 6):
    p = p * i
print(p)

→ 120

Счётчик

k = 0
for x in range(1, 21):
    if x % 3 == 0:
        k = k + 1
print(k)

→ 6

Накопитель создаём до цикла: сумму и счётчик — с 0, произведение — с 1.

Спросите: почему произведение начинают с 1? (с 0 всё время будет 0).
