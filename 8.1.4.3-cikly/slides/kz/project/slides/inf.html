Шексіз цикл және break

Қате

i = 1
while i <= 5:
    print(i)

i өзгермейді → шарт әрқашан ақиқат → бағдарлама тоқтамайды.

Түзетілген

i = 1
while i <= 5:
    print(i)
    i = i + 1

Цикл денесінде шарттағы айнымалыны өзгертеміз.

break

i = 1
while True:
    if i * i > 50:
        break
    i = i + 1
print(i)

→ 8

break — циклден бірден шығу.

Қатып қалған бағдарламаны тоқтату: Ctrl + C немесе «Тоқтату» батырмасы. Веб-ресурста шексіз цикл 1 секундтан кейін өзі тоқтайды.
