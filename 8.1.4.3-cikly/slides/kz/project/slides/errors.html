Жиі кездесетін қателер

1. range соңы кірмейді

1-ден n-ге дейінгі сандар:

Қате

range(1, n)

Дұрыс

range(1, n + 1)

2. Жинақтауыш цикл ішінде

s = 0 — цикл алдында, әйтпесе қосынды нөлденеді:

Қате

for i in a:
    s = 0
    s = s + i

Дұрыс

s = 0
for i in a:
    s = s + i

3. print-тегі артық шегініс

Бір рет — циклден кейін шығарамыз:

Қате

for i in a:
    s = s + i
    print(s)

Дұрыс

for i in a:
    s = s + i
print(s)

4. while айнымалысы өзгермейді

i = i + 1 болмаса, цикл шексіз:

Қате

while i <= 5:
    print(i)

Дұрыс

while i <= 5:
    print(i)
    i = i + 1

3-қатені 1..5 қосындысы мысалында көрсетіңіз: шегініспен 1, 3, 6, 10, 15 шығады, шегініссіз — тек 15.
