Бағдарлама не шығарады?

1-бағдарлама

s = 0
for i in range(1, 10, 3):
    s = s + i
print(s)

2-бағдарлама

k = 0
n = 5047
while n > 0:
    k = k + 1
    n = n // 10
print(k)

Жауапты дәптерге жазыңыз, содан кейін іске қосып тексереміз.

Жауаптар: 1-бағдарлама — 12 (1 + 4 + 7), 2-бағдарлама — 4 (5047 санында төрт цифр). Python-да іске қосылып тексерілген.
