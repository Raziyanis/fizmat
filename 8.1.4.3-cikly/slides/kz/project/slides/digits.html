while: қайталану саны алдын ала белгісіз

n = 2026
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)

2026 санының цифрларының қосындысы = 10. n % 10 — соңғы цифр, n // 10 — онсыз сан.
