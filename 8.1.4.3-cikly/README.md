# 8.1.4.3 — цикл while, цикл for

Шаг 1. `teoriya-8.1.4.3.docx` — теория для учащихся: range (3 формы, отрицательный шаг, пустой range), вывод в строку,
for x in список / for i in range(len(...)), накопители с трассировкой, while (счётчик, цифры числа, ввод до 0,
бесконечный цикл, break/continue), сравнение for и while, частые ошибки, шпаргалка.

Код всех примеров и их вывод — `tools/examples.py` → `tools/examples.json` (вывод получен запуском Python, вручную не пишется).
Сборка: `python3 tools/examples.py && NODE_PATH=<пакет docx> node tools/build-teoriya.js`.

Шаг 2. `formativ/standalone/formativ-8.1.4.3.html` — тестовое задание (веб, один файл, без интернета): 20 заданий, 20 минут,
пароль учителя 2026 (`formativ/config.js`). У каждого ученика свои числа; после работы — разбор с правильными ответами.
Ключ: `python3 formativ/tools/check-tasks.py` (код каждого задания выполняется настоящим Python). Сборка: `node formativ/tools/build-standalone.js`.

Шаг 3 (итоговый веб-ресурс). `web/standalone/cikly-8.1.4.3.html` — один файл, без интернета:
1) теория (тот же текст, что в Word: оба собираются из `tools/theory-content.js`), таймер не идёт;
2) тест — 10 вопросов: выбор ответа A–D и сопоставление;
3) 10 задач на код уровней A (1–4), B (5–7), C (8–10): ученик пишет программу на Python (можно for или while),
   код выполняется в браузере (Skulpt) на 8 тестах; все тесты пройдены — 1 балл, иначе 0.
Ввод засчитывается любым способом: числа одной строкой (input().split()) или каждое отдельным input().
В разборе к каждой задаче два образца решения — разными циклами (for / while).
Тест проверяется отдельно, сразу после сдачи: ученик видит балл и где ошибся (каждый вопрос показан с ответом ученика,
правильным ответом и ссылкой на раздел теории). При низком балле можно перечитать теорию и пройти тест заново: в новой попытке
другие числа, а вопросы 5–7 берутся из банка формулировок (в трёх попытках — три разные);
до 3 попыток, засчитывается лучшая. Время: тест — 15 минут на попытку, задачи на код — 80 минут.
Максимум 20 баллов; всё меняется в `web/config.js`. Работа открывается кнопкой «Начать (на весь экран)» и вся идёт в полноэкранном режиме,
включая теорию. Выход из полноэкранного режима, смена вкладки или окна, перезагрузка страницы — нарушение: за первые два —
предупреждение «осталось попыток: N» и кнопка возврата на весь экран (после перезагрузки работа продолжается с того же места),
на третьем (`MAX_VIOLATIONS`) работа завершается. Результат виден 4 минуты (`RESULT_MIN`), затем открывается начальная страница;
новая работа начинается без пароля.
Язык интерфейса — кнопки ҚАЗ / РУС (видны на всех экранах, в том числе поверх предупреждения о нарушении).
Клавиатура: ресурс перехватывает только Esc, поэтому раскладка в Windows переключается как обычно (Alt+Shift, Win+Пробел);
кроме того, в редакторе кода включён режим «⌨ Латиница» — при любой раскладке клавиши вводят английские символы
(по физической клавише); кнопкой он выключается, чтобы писать кириллицей.
Проверка ключа: `python3 web/tools/check.py` (образцы и решения другим циклом — настоящим Python). Сборка: `node web/tools/build-standalone.js`.
