for … else — «табылмады» жағдайы

else цикл break-сіз аяқталғанда ғана орындалады. else — for-пен бір деңгейде, if астында емес.

for x in [4, 8, 15, 16]:
    if x % 5 == 0:
        print("found:", x)
        break
else:
    print("no multiples of 5")

found: 15

break болды → else орындалмады

while … else да осылай: шарт жалған болып, цикл өзі аяқталса — else орындалады. Мысалы: k = 3; while k > 0: print(k); k = k − 1; else: print("start!") → 3 2 1 start!
