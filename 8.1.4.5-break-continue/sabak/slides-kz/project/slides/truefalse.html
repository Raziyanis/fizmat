True және False — логикалық мәндер

Кез келген салыстыру True (ақиқат) немесе False (жалған) береді. Бас әріппен жазылады. if пен while дәл осыны тексереді.

print(5 > 3)
print(5 == 3)
x = 7
print(x % 2 == 0)

True
False
False

go = True
n = 0
while go:
    n = n + 1
    if n * n > 20:
        go = False
print("stop:", n)

stop: 5

Жалауша (флаг) — True/False сақтайтын айнымалы. Ол False болғанда while келесі тексеруде тоқтайды. while True — шарты әрқашан ақиқат цикл, ал while False бірде-бір рет орындалмайды. Нәтижелер Python-да тексерілген.
