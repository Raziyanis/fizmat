Ішкі циклдағы break

break тек өзі тұрған циклды тоқтатады. Екеуін де тоқтату үшін — жалауша (flag).

found = False
for i in range(1, 10):
    for j in range(1, 10):
        if i * j == 24:
            print(i, j)
            found = True
            break
    if found:
        break

Ішкі break → тек j бойынша цикл тоқтайды. Сыртқы break → found тексеріліп, i бойынша цикл да тоқтайды.

Екінші break болмаса, программа 4 6, 6 4, 8 3 жұптарын да шығарар еді. Бұл тәсіл 10-есепте (қосындысы S жұп) керек.
