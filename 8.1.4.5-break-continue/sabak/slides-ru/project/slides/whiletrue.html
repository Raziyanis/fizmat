while True + break

Цикл с всегда истинным условием сам не остановится — внутри обязателен break. Удобен, когда число шагов неизвестно.

while True:
    word = input()
    if word == "stop":
        break
    print(word.upper())
print("bye")

Ввод

cat
dog
stop
fox

Вывод

CAT
DOG
bye

Схема: 1) прочитать → 2) проверить условие остановки (break) → 3) обработать

Пришло «stop» — break: «fox» не прочитано, само слово «stop» не обработано. Проверка должна стоять сразу после ввода — иначе значение-остановка тоже попадёт в обработку.
