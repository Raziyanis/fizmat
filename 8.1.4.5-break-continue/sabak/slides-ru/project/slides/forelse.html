for … else — случай «не найдено»

else выполняется, только если цикл закончился без break. else — на уровне for, а не под if.

for x in [4, 8, 15, 16]:
    if x % 5 == 0:
        print("found:", x)
        break
else:
    print("no multiples of 5")

found: 15

был break → else не выполнился

for x in [4, 8, 16]:
    if x % 5 == 0:
        print("found:", x)
        break
else:
    print("no multiples of 5")

no multiples of 5

break не было → выполнился else

while … else работает так же: условие стало ложным и цикл закончился сам — выполняется else. Пример: k = 3; while k > 0: print(k); k = k − 1; else: print("start!") → 3 2 1 start!
