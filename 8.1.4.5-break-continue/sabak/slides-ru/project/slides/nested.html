break во вложенном цикле

break останавливает только тот цикл, где стоит. Чтобы остановить оба — флаг.

found = False
for i in range(1, 10):
    for j in range(1, 10):
        if i * j == 24:
            print(i, j)
            found = True
            break
    if found:
        break

Вывод

3 8

Внутренний break → останавливается только цикл по j. Внешний break → после проверки found останавливается и цикл по i.

Без второго break программа вывела бы ещё пары 4 6, 6 4, 8 3. Этот приём нужен в задаче 10 (пара с суммой S).
