# 8.1.4.5 — Циклді басқару: break, continue, else / Управление циклом: break, continue, else

`web/standalone/break-continue-8.1.4.5.html` — дайын файл / готовый файл. Бір файл, интернет пен сервер қажет емес:
Python интерпретаторы (Skulpt, MIT, `web/vendor/LICENSE`) файлдың ішінде / один файл, Python работает прямо в браузере.

- Бастапқы бет: нұсқаулық, аты-жөні және сыныбы. Содан кейін **теория** (уақыт жүрмейді): True/False, break, while True, continue, циклдағы else, ішкі циклдағы break, жиі қателер, шпаргалка; мысалдардың нәтижесі нағыз Python-да алынған (`web/tools/build-theory.py`).
  Жұмыс кезінде теорияны «📖 Теория» батырмасымен кез келген уақытта ашуға болады (код пен таймер сақталады, бұзушылық емес).
- 13 олимпиадалық есеп, жеңілден қиынға: A (1–4), B (5–7), C (8–13). Әр есепте шарт, кіріс/шығыс деректер форматы, 2 мысал.
  1 До нуля (break) · 2 Пропуск чисел (continue) · 3 Первое отрицательное/чётное (break + for…else) · 4 Простое ли число (break + else) ·
  5 Покупки (break) · 6 Показания датчика (continue + break) · 7 PIN-код (break + else) · 8 Числа без цифры d (continue) ·
  9 Ближайшее простое (вложенный for…else + break) · 10 Пара с суммой S (break из вложенных циклов) ·
  11 Длинные слова (continue + break) · 12 Вклад в банке (while…else + break) · 13 Первые k простых (for…else + break).
- Әр есеп 8 тестте тексеріледі (2 мысал + 6 жасырын). 1 балл — барлық тест өтсе **және** шартта көрсетілген нұсқаулар
  (break / continue / циклдың else бөлігі) программада болса. Ең көбі 13 балл. Әр оқушының сандары мен тесттері әртүрлі.
- Толық экран; шығу, басқа бетке ауысу, қайта жүктеу — бұзушылық: 2 ескерту, 3-інде жұмыс аяқталады.
- Нәтиже: балл, есептер кестесі (тесттер, нұсқаулар), оқушының коды мен үлгі шешім, бірінші қате тест. 5 минуттан кейін бастапқы бет ашылады.
- ҚАЗ / РУС ауыстырғышы кез келген уақытта.
- Баптаулар `web/config.js`: `WORK_MIN` (80 минут), `RESULT_MIN`, `MAX_VIOLATIONS`.
- Кілтті тексеру: `python3 web/tools/check.py` — үлгі шешімдер нағыз Python-да 300 нұсқаның барлық тестінде орындалады.
  Жинау: `python3 web/tools/build-theory.py && node web/tools/build-standalone.js`.
