1. Циклді не үшін басқарамыз?1. Зачем управлять циклом?

Әдетте цикл шарты жалған болғанша (while) немесе тізбектің барлық элементі біткенше (for) жұмыс істейді. Бірақ кейде циклды ертерек тоқтату немесе бір қадамды өткізіп жіберу керек болады. Ол үшін Python-да үш нұсқау бар:

Обычно цикл работает, пока условие истинно (while) или пока не закончатся все элементы последовательности (for). Но иногда цикл нужно остановить раньше или пропустить один шаг. Для этого в Python есть три инструкции:

breakциклды бірден тоқтатадысразу прекращает цикл
continueкелесі қадамға өтедіпереходит к следующему шагу
elseцикл break-сіз аяқталса орындаладывыполняется, если цикл закончился без break

2. break — циклды тоқтату2. break — остановить цикл

break орындалғанда цикл бірден аяқталады: қалған жолдар да, қалған қадамдар да орындалмайды. Программа циклдан кейінгі жолдан жалғасады. Әдетте break шартпен бірге жазылады: if …: break.

Когда выполняется break, цикл сразу заканчивается: не выполняются ни оставшиеся строки, ни оставшиеся шаги. Программа продолжается со строки после цикла. Обычно break пишут вместе с условием: if …: break.

ПрограммаПрограмма
for i in range(1, 10):
    if i == 4:
        break
    print(i)
print("end")
НәтижеВывод
1
2
3
end

range(1, 10) 9 қадамға есептелген, бірақ i = 4 болғанда break орындалды: 4 саны шықпады, цикл тоқтады, «end» шықты.

range(1, 10) рассчитан на 9 шагов, но при i = 4 сработал break: число 4 не вывелось, цикл остановился, вывелось «end».

3. True және False — логикалық мәндер3. True и False — логические значения

Python-да екі логикалық мән бар: True (ақиқат) және False (жалған). Бас әріппен жазылады: true, false деп жазсаңыз — қате. Кез келген салыстыру (>, <, ==, !=, >=, <=) True немесе False береді. if пен while дәл осы мәнді тексереді: True — орындалады, False — орындалмайды.

В Python два логических значения: True (истина) и False (ложь). Пишутся с большой буквы: true, false — ошибка. Любое сравнение (>, <, ==, !=, >=, <=) даёт True или False. Именно это значение проверяют if и while: True — выполняется, False — нет.

ПрограммаПрограмма
print(5 > 3)
print(5 == 3)
x = 7
print(x % 2 == 0)
ok = x > 0
print(ok)
НәтижеВывод
True
False
False
True

True/False айнымалыда сақталуы мүмкін — оны жалауша (флаг) деп атайды. Цикл жалауша True болғанша жұмыс істейді, ал оны False қылсақ — тоқтайды. Бұл break-ке балама тәсіл: айырмасы — False қойылған соң қадамның қалған бөлігі орындалады, ал цикл келесі тексеруде тоқтайды.

True/False можно хранить в переменной — её называют флагом. Цикл работает, пока флаг равен True, а когда мы делаем его False — останавливается. Это альтернатива break; разница: после False остаток шага выполняется, а цикл останавливается при следующей проверке условия.

ПрограммаПрограмма
go = True
n = 0
while go:
    n = n + 1
    if n * n > 20:
        go = False
    print(n, n * n)
print("stop:", n)
НәтижеВывод

n = 5 болғанда 25 > 20, go = False болды, бірақ print(n, n * n) бәрібір орындалды (5 25). break болса, ол жол орындалмас еді.

При n = 5: 25 > 20, go стал False, но print(n, n * n) всё равно выполнился (5 25). С break эта строка не выполнилась бы.

while True: — шарты әрқашан True цикл, ал while False: бірде-бір рет орындалмайды.

while True: — цикл, условие которого всегда True, а while False: не выполнится ни разу.

4. while True — шексіз цикл және break4. while True — бесконечный цикл и break

while True: — шарты әрқашан ақиқат цикл. Ол өздігінен ешқашан тоқтамайды, сондықтан ішінде міндетті түрде break болуы керек. Бұл тәсіл қашан тоқтау керегі алдын ала белгісіз болғанда ыңғайлы: мысалы, деректерді белгілі бір мән келгенше енгізу.

while True: — цикл, условие которого всегда истинно. Сам он никогда не остановится, поэтому внутри обязательно должен быть break. Такой приём удобен, когда заранее неизвестно, сколько будет шагов: например, ввод данных до определённого значения.

ПрограммаПрограмма
while True:
    word = input()
    if word == "stop":
        break
    print(word.upper())
print("bye")

«stop» сөзі келгенде break орындалды, сондықтан одан кейінгі «fox» сөзі оқылмады. Тексеру (if … break) енгізуден кейін бірден тұр: «stop» сөзінің өзі өңделмейді.

Когда пришло слово «stop», сработал break, поэтому следующее слово «fox» не было прочитано. Проверка (if … break) стоит сразу после ввода: само слово «stop» не обрабатывается.

Схема: 1) прочитать → 2) проверить условие остановки (break) → 3) обработать.

5. continue — қадамды өткізіп жіберу5. continue — пропустить шаг

continue орындалғанда ағымдағы қадамның қалған бөлігі өткізіледі, ал цикл тоқтамайды — бірден келесі қадамға өтеді. for циклында айнымалы келесі мәнді алады, while циклында шарт қайта тексеріледі.

Когда выполняется continue, остаток текущего шага пропускается, но цикл не останавливается — сразу начинается следующий шаг. В цикле for переменная получает следующее значение, в цикле while заново проверяется условие.

ПрограммаПрограмма
for word in ["sun", "", "sky", "", "sea"]:
    if word == "":
        continue
    print(word)

7. Циклдағы else7. else в цикле

for және while циклдарының else бөлігі болуы мүмкін. Ол цикл break-сіз, қалыпты аяқталғанда ғана орындалады. Егер цикл break арқылы тоқтаса, else орындалмайды. Сондықтан for … else іздеу есептеріне ыңғайлы: «таптым — break», «таппадым — else».

У циклов for и while может быть часть else. Она выполняется, только если цикл закончился обычным образом, без break. Если цикл остановлен через break, else не выполняется. Поэтому for … else удобен в задачах поиска: «нашёл — break», «не нашёл — else».

ПрограммаПрограмма
for x in [4, 8, 15, 16]:
    if x % 5 == 0:
        print("found:", x)
        break
else:
    print("no multiples of 5")
НәтижеВывод
found: 15
ПрограммаПрограмма
for x in [4, 8, 16]:
    if x % 5 == 0:
        print("found:", x)
        break

    print("no multiples of 5")

Бірінші мысалда 15 табылды → break → else орындалмады. Екіншісінде 5-ке еселі сан жоқ → цикл соңына дейін жетті → else орындалды.

В первом примере найдено 15 → break → else не выполнился. Во втором кратных 5 нет → цикл дошёл до конца → выполнился else.

Назар аударыңыз: else сөзі for (немесе while) сөзімен бір деңгейде жазылады, if астында емес. else-ті if-пен бір деңгейде жазсаңыз, ол циклдың емес, if-тің бөлігі болады.

Внимание: слово else пишется на одном уровне с for (или while), а не под if. Если написать else на уровне if, это будет часть if, а не цикла.

while … else да осылай жұмыс істейді: шарт жалған болып, цикл өзі аяқталса — else орындалады.

while … else работает так же: если условие стало ложным и цикл закончился сам — выполняется else.

    print("start!")

8. Ішкі циклдағы break8. break во вложенном цикле

break тек өзі тұрған циклды тоқтатады. Ішкі циклдағы break сыртқы циклды тоқтатпайды.

break останавливает только тот цикл, в котором стоит. break во внутреннем цикле не останавливает внешний.

ПрограммаПрограмма
for i in range(1, 4):
    for j in range(1, 4):
        if j > i:
            break
        print(i, j)
НәтижеВывод
1 1
2 1
2 2
3 1
3 2
3 3

Екі циклды да тоқтату керек болса, жалауша (flag) айнымалысын қолданамыз: ішкі циклда found = True қойып, break жасаймыз; сыртқы циклда found тексеріп, тағы break жасаймыз.

Если нужно остановить оба цикла, используем переменную-флаг: во внутреннем цикле ставим found = True и делаем break; во внешнем проверяем found и снова делаем break.

ПрограммаПрограмма
found = False
for i in range(1, 10):
    for j in range(1, 10):
        if i * j == 24:
            print(i, j)
            found = True
            break
    if found:
        break

9. Жиі кездесетін қателер9. Частые ошибки

  • break немесе continue циклдан тыс — SyntaxError. Олар тек for немесе while ішінде жазылады.
  • while True ішінде break жоқ — шексіз цикл, программа тоқтамайды.
  • while ішінде continue санауыштан бұрын тұр — i = i + 1 жолы өткізіледі, i өзгермейді, цикл шексіз болады. Санауышты continue-ден бұрын өзгертіңіз.
  • else if-пен бір деңгейде — ол циклдың else-і емес, if-тің else-і болып шығады.
  • Тоқтау шарты өңдеуден кейін тексеріледі — тоқтау мәні (мысалы, 0) де есептеліп кетеді. Алдымен тексеріп, сосын өңдеңіз.
  • break или continue вне цикла — ошибка SyntaxError. Их пишут только внутри for или while.
  • В while True нет break — бесконечный цикл, программа не остановится.
  • continue в while стоит до изменения счётчика — строка i = i + 1 пропускается, i не меняется, цикл становится бесконечным. Меняйте счётчик до continue.
  • else на уровне if — получается else от if, а не от цикла.
  • Условие остановки проверяется после обработки — значение-остановка (например, 0) тоже попадает в подсчёт. Сначала проверяйте, потом обрабатывайте.

Циклды бірден тоқтатады. Программа циклдан кейінгі жолдан жалғасады.Сразу прекращает цикл. Программа продолжается со строки после цикла.

Ағымдағы қадамның қалған бөлігін өткізіп, циклдың келесі қадамына өтеді.Пропускает остаток текущего шага и переходит к следующему шагу цикла.

for … else

else бөлігі цикл break-сіз соңына дейін жеткенде ғана орындалады.Часть else выполняется, только если цикл дошёл до конца без break.

for ch in "python":

        print("found")
        break
else:
    print("not found")

while True / False

while True — өзі тоқтамайтын цикл, ішінде break міндетті. Жалауша False болса, цикл тоқтайды.while True — цикл, который сам не остановится, внутри обязателен break. Если флаг стал False, цикл останавливается.

while True:
    s = input()
    if s == "stop":
        break
    print(s)
