Циклді басқару: break, continue, elseУправление циклом: break, continue, else

8.1.4.5 — циклді басқару нұсқауларын қолдану (continue, break, else)8.1.4.5 — использовать инструкции управления циклом (continue, break, else)

Еске түсірейікВспомним

break

Циклды бірден тоқтатады. Программа циклдан кейінгі жолдан жалғасады.Сразу прекращает цикл. Программа продолжается со строки после цикла.

for i in range(1, 100):
    if i * i > 30:
        break
    print(i, end=" ")
# 1 2 3 4 5

continue

Ағымдағы қадамның қалған бөлігін өткізіп, циклдың келесі қадамына өтеді.Пропускает остаток текущего шага и переходит к следующему шагу цикла.

for ch in "informatika":
    if ch in "aeiou":
        continue
    print(ch, end="")
# nfrmtk

for … else

else бөлігі цикл break-сіз соңына дейін жеткенде ғана орындалады.Часть else выполняется, только если цикл дошёл до конца без break.

for ch in "python":
    if ch == "z":
        print("found")
        break
else:
    print("not found")
# not found

НұсқаулықИнструкция

  • 10 есеп — жеңілден қиынға қарай: A деңгейі (1–4), B (5–7), C (8–10). Әр есепке Python-да программа жазыңыз.10 задач — от простого к сложному: уровень A (1–4), B (5–7), C (8–10). К каждой задаче напишите программу на Python.
  • Есептер олимпиададағыдай: деректерді input() арқылы оқып, жауапты print() арқылы шығарыңыз. Әр есепте кіріс және шығыс деректердің мысалдары бар.Задачи — как на олимпиаде: данные читайте через input(), ответ выводите через print(). У каждой задачи есть примеры входных и выходных данных.
  • «▶ Іске қосу» — программаны өз деректеріңізбен орындау. «✓ Тексеру» — 8 тестте тексеру (2 мысал + 6 жасырын тест).«▶ Запустить» — выполнить программу со своими данными. «✓ Проверить» — проверка на 8 тестах (2 примера + 6 скрытых).
  • Есеп 1 балл: 8 тесттің бәрінен өтсе және шартта көрсетілген нұсқаулар (break, continue, else) программада болса. Ең көбі — 10 балл.Задача — 1 балл: если пройдены все 8 тестов и в программе есть инструкции, указанные в условии (break, continue, else). Максимум — 10 баллов.
  • Уақыт — минут. Есептер арасында еркін ауысуға болады, код өздігінен сақталады. Балл жұмыс аяқталғанда соңғы код бойынша есептеледі.Время — минут. Между задачами можно свободно переходить, код сохраняется автоматически. Балл считается по последней версии кода, когда работа завершается.
  • Кодты кез келген пернетақта тілінде жазуға болады: редактордың үстіндегі «⌨ Латиница» режимі пернелерге ағылшын әріптерін береді.Код можно писать при любой раскладке: режим «⌨ Латиница» над редактором вводит английские буквы и знаки.
  • Жұмыс толық экранда жүреді. Одан шығу, басқа бетке не терезеге ауысу, бетті қайта жүктеу — бұзушылық. Алғашқы екеуіне ескерту беріледі, үшіншісінде жұмыс аяқталады.Работа идёт в полноэкранном режиме. Выход из него, переход на другую вкладку или окно, перезагрузка страницы — нарушение. За первые два — предупреждение, на третьем работа завершается.

Бұл браузер толық экранды қолдамайды. Басқа беттерге ауыспаңыз.Этот браузер не поддерживает полноэкранный режим. Не переключайтесь на другие вкладки.
